# 二叉树（Binary Tree）

[English](./README.md) | 简体中文

术语遵循[共享术语表](../../docs/GLOSSARY.md)，数学记号遵循仓库的 [GitHub 数学书写规范](../../docs/GITHUB_MATH.md)。

本文是二叉树的总体笔记：定义、表示、遍历与代价，以及在题目中反复出现的使用模式。各应用题的题解只写“这道题怎么用二叉树”，二叉树本身的知识集中在这里。

## 1. 定义

CLRS 附录 B.5.3 用递归方式定义二叉树：二叉树要么**不含任何结点**（空树），要么由三个互不相交的部分组成——**根**结点、称为**左子树**的二叉树、称为**右子树**的二叉树。

常用术语：

| 术语 | 含义 |
|---|---|
| 叶结点 | 左右子树都为空的结点 |
| 深度 | 从根到该结点的路径上的边数，根的深度为 0 |
| 高度 | 从该结点到其子树中最深叶结点的边数；树的高度即根的高度 |
| 满二叉树 | 每个结点要么是叶结点，要么恰有两个孩子 |
| 完全二叉树 | CLRS 中指所有叶结点深度相同、内部结点都有两个孩子的树；力扣题目里的“完全二叉树”通常指“除最后一层外全满、最后一层靠左”的树，与 CLRS 用法不同 |

递归定义是二叉树题目的核心：几乎所有算法都写成“处理根，再递归处理两棵子树”，正确性也几乎都用**对子树大小的归纳**来证明。

## 2. 表示与代价

### 2.1 CLRS 的链式表示（§10.4）

每个结点 `x` 存关键字 `x.key` 和三个指针：`x.p`（父结点）、`x.left`、`x.right`。缺失的孩子或父结点用 NIL 表示，`T.root` 指向根，`T.root = NIL` 表示空树。

### 2.2 Go 中的写法

力扣的 Go 题目统一使用下面的结点定义，没有父指针：

```go
type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}
```

- 空树就是 `nil` 指针。递归函数的第一行通常是 `if root == nil { return ... }`，这一行同时就是归纳证明的基础情况。
- 没有父指针，所以“向上走”的操作要么用递归返回值把信息带回父结点，要么自己用栈或哈希表记录父结点。
- 本地写测试时，需要把力扣的层序数组（如 `[1,null,2,3]`）还原成树。仓库在测试文件中用 `[]any` 表示，`nil` 代表缺失的孩子，按层序用队列逐个挂上子结点。

### 2.3 遍历的代价

设树有 $`n`$ 个结点、高度为 $`h`$。

- **时间**：每个结点恰好被访问一次，遍历是 $`\Theta(n)`$（CLRS 定理 12.1 对中序遍历给出了这个结论，前序、后序同理）。
- **空间**：递归深度等于 $`h + 1`$，调用栈占 $`O(h)`$。$`h`$ 介于 $`\lfloor \lg n \rfloor`$（平衡树）和 $`n - 1`$（退化成链）之间，所以最坏是 $`O(n)`$。分析空间复杂度时要写 $`O(h)`$ 并说明最坏情况，不能直接写 $`O(\lg n)`$。
- **Go 的切片拼接**：如果递归函数每层都返回一个新切片，再用 `append(res, child...)` 拼起来，每个值会在它的每个祖先处被复制一次，总复制量是 $`\sum_v \mathrm{depth}(v) = O(nh)`$，链状树上退化为 $`\Theta(n^2)`$。把结果切片作为参数（或闭包变量）传下去、只在访问结点时 `append` 一次，就能回到 $`\Theta(n)`$。

## 3. 常见使用模式

每种模式下列出“递归函数做什么”和“何时适用”。后续有新题时补充到对应模式下。

### 3.1 三种深度优先遍历顺序

- **前序**：根 → 左 → 右。适用于“先处理父结点、再把信息传给孩子”的问题，以及序列化一棵树。
- **中序**：左 → 根 → 右。对**二叉搜索树**，中序遍历按关键字从小到大输出（CLRS §12.1），所以验证 BST、求第 $`k`$ 小元素都用中序。
- **后序**：左 → 右 → 根。适用于“父结点的答案依赖两个孩子的答案”的问题，例如高度、直径、删除整棵树。
- **证明方法**：对子树结点数做强归纳，假设递归调用对两棵子树正确，再证明拼接后对整棵树正确。

### 3.2 自底向上返回信息（后序）

- **递归函数做什么**：返回子树的某个汇总值（高度、结点数、是否平衡等），父结点用两个孩子的返回值计算自己的值。
- **何时适用**：答案可以由左右子树的答案合并得到。若最终答案与返回值不同（例如直径不等于高度），就再用一个外部变量在每个结点处更新全局最优。

### 3.3 自顶向下传递信息（前序）

- **递归函数做什么**：把从根到当前结点路径上的信息（当前路径和、深度、允许的取值范围）作为参数传给孩子。
- **何时适用**：判断条件依赖祖先，例如验证 BST 时向下传递取值上下界、路径总和问题。

### 3.4 层序遍历（广度优先）

- **用什么**：队列，按层处理；每轮先记下当前队列长度，就能把同一层的结点分在一组。
- **何时适用**：按层输出、右视图、最小深度等与“层”有关的问题。对应 CLRS §22.2 广度优先搜索在树上的特例。

### 3.5 用显式栈代替递归

- **做法**：用栈保存“还没处理完的祖先”。中序遍历的迭代写法是：一路向左压栈，弹出时访问，再转向右子树。
- **何时适用**：递归太深可能栈溢出，或需要像迭代器一样一步一步产出结点。CLRS 练习 10.4-3 要求用栈非递归地遍历二叉树，练习 12.1-3 要求非递归地中序遍历。
- **进一步**：Morris 遍历利用空的右指针临时串起线索，把额外空间降到 $`O(1)`$，代价是遍历过程中会临时修改树。
