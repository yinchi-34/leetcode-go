## 2. 题意理解（Problem Understanding）

给定一个未排序的整数数组 `nums`，找出最长的一组**数值连续**的数（例如 1, 2, 3, 4）的长度。这些数在原数组中不要求相邻，也不要求按顺序出现。题目要求时间复杂度 $`O(n)`$。

**示例**

- 输入：`nums = [100,4,200,1,3,2]`
- 输出：`4`（最长连续序列是 1, 2, 3, 4）

**关键要求**

1. $`0 \le \mathrm{nums.length} \le 10^5`$，$`-10^9 \le \mathrm{nums}[i] \le 10^9`$。
2. 时间复杂度要求 $`O(n)`$，所以先排序再扫描的 $`O(n \log n)`$ 做法不满足题目要求。
3. 数组可能为空（答案为 0），可能有重复元素（重复的数只算一次，例如 `[1,0,1,2]` 的答案是 3），可能有负数。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 散列集合段首扩展（Hash Set Run-Head Extension）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`0 \le n \le 10^5`$
- $`-10^9 \le a_i \le 10^9`$

记 $`S = \{a_0, a_1, \ldots, a_{n-1}\}`$ 为 $`A`$ 中不同值组成的集合，$`m = |S| \le n`$。

### 4.2 输出（Output）

称整数集合 $`\{x, x+1, \ldots, x+L-1\}`$（$`L \ge 1`$）为长度为 $`L`$ 的**连续序列**。输出

```math
\mathrm{res} = \max\bigl\{\, L \;:\; \exists x,\ \{x, x+1, \ldots, x+L-1\} \subseteq S \,\bigr\}
```

当 $`S = \varnothing`$ 时规定 $`\mathrm{res} = 0`$。

### 4.3 伪代码（Pseudocode）

本题不按下标访问数组，伪代码中没有索引。

```text
LONGEST-CONSECUTIVE(A)
    S ← empty set
    for each a in A
        INSERT(S, a)

    res ← 0
    for each x in S
        if x - 1 ∉ S                     // x 是段首
            cur ← x
            len ← 1
            while cur + 1 ∈ S
                cur ← cur + 1
                len ← len + 1
            res ← max(res, len)

    return res
```

**状态定义**

- `S`：对应代码中的 `numSet`，`A` 中全部不同值组成的散列集合。
- `cur`：对应 `currentNum`，当前段已经扩展到的最大值。
- `len`：对应 `currentStreak`，当前段已经扩展的长度。
- `res`：已处理过的段首中，最长段的长度。

代码用 `if res <= currentStreak { res = currentStreak }` 实现 `max`，取等时重新赋同一个值，结果相同。

### 4.4 正确性（Correctness）

**证明方法：极大连续段的划分 + 内层与外层循环不变式**

#### 一、正确性依赖的关键条件

先给出两个定义。

- **极大连续段**（maximal run）：$`S`$ 的子集 $`\{h, h+1, \ldots, h+L-1\}`$，满足它包含于 $`S`$，且 $`h - 1 \notin S`$、$`h + L \notin S`$，即两端都不能再延长。
- **段首**（run head）：满足 $`h \in S`$ 且 $`h - 1 \notin S`$ 的值 $`h`$。

算法正确性依赖于：

1. **集合的有限性**（题目给定）：$`S`$ 是有限集合，所以从任何元素出发向上或向下逐个走，都会在有限步内走出 $`S`$。
2. **段首与极大段一一对应**（引理 1）：每个段首 $`h`$ 唯一确定一个以它开头的极大段，长度记为 $`L(h)`$；每个极大段的最小元素都是段首。
3. **任意连续序列都落在某个极大段内**（引理 2）：这保证只看段首不会漏掉答案。

#### 二、正确性证明

**引理 1（内层循环）**：设 $`x`$ 是段首。内层 `while` 循环终止，且终止时 $`\mathrm{len} = L(x)`$。

*循环不变式*：每次检查 `while` 条件时，$`\mathrm{cur} = x + \mathrm{len} - 1`$，且 $`\{x, x+1, \ldots, \mathrm{cur}\} \subseteq S`$。

- **初始化**：$`\mathrm{cur} = x`$，$`\mathrm{len} = 1`$，$`x \in S`$，成立。
- **保持**：进入循环体说明 $`\mathrm{cur} + 1 \in S`$。`cur` 与 `len` 各加 1 后，等式仍成立，集合多了一个属于 $`S`$ 的元素 $`\mathrm{cur}+1`$，仍包含于 $`S`$。
- **终止**：$`\{x, \ldots, \mathrm{cur}\} \subseteq S`$ 中的元素互不相同，所以 $`\mathrm{len} \le m`$，循环至多执行 $`m - 1`$ 次后必然退出。退出时 $`\mathrm{cur} + 1 \notin S`$，又因为 $`x`$ 是段首，$`x - 1 \notin S`$，所以 $`\{x, \ldots, \mathrm{cur}\}`$ 两端都不能延长，正是以 $`x`$ 开头的极大段，$`\mathrm{len} = L(x)`$。

**引理 2（解的完整性）**：若 $`\{a, a+1, \ldots, a+L-1\} \subseteq S`$，则存在段首 $`h \le a`$，使 $`L \le L(h)`$。

*证明*：从 $`a`$ 向下走：只要当前值减 1 仍在 $`S`$ 中就继续。由条件 1，这一过程在有限步内停在某个 $`h \le a`$，且 $`h \in S`$、$`h - 1 \notin S`$，所以 $`h`$ 是段首，并且 $`\{h, \ldots, a\} \subseteq S`$。于是 $`\{h, \ldots, a+L-1\} \subseteq S`$ 是从 $`h`$ 开始的一段连续序列。以 $`h`$ 开头的极大段是从 $`h`$ 出发能延伸到的最长连续序列，所以 $`L(h) \ge (a + L - 1) - h + 1 \ge L`$。

**外层循环不变式**

设外层循环已经处理过的元素组成集合 $`T \subseteq S`$。在每次外层迭代开始时：

**不变式：已处理段首的最大段长**

$`\mathrm{res} = \max\{L(h) : h \in T,\ h \text{ 是段首}\}`$；$`T`$ 中没有段首时 $`\mathrm{res} = 0`$。

**初始化（Initialization）**

$`T = \varnothing`$，$`\mathrm{res} = 0`$，成立。

**保持（Maintenance）**

假设处理元素 $`x`$ 之前不变式成立。

- **情况一：$`x - 1 \in S`$**。$`x`$ 不是段首，算法不修改 `res`；$`T \cup \{x\}`$ 中的段首与 $`T`$ 中相同，不变式仍成立。
- **情况二：$`x - 1 \notin S`$**。$`x`$ 是段首，由引理 1，内层循环算出 $`\mathrm{len} = L(x)`$，随后 $`\mathrm{res} \leftarrow \max(\mathrm{res}, L(x))`$，正好把 $`x`$ 纳入最大值，不变式仍成立。

**终止（Termination）**

外层循环恰好遍历 $`S`$ 的 $`m`$ 个元素后结束，此时 $`T = S`$，$`\mathrm{res} = \max\{L(h) : h \text{ 是段首}\}`$。

- **可达**：每个段首 $`h`$ 的极大段本身就是一段长度为 $`L(h)`$ 的连续序列，所以 $`\mathrm{res}`$ 不超过题目要求的最大值。
- **上界**：由引理 2，任意连续序列的长度都不超过某个 $`L(h)`$，所以 $`\mathrm{res}`$ 不小于题目要求的最大值。

两者合起来，$`\mathrm{res}`$ 等于最长连续序列的长度。$`S = \varnothing`$ 时外层循环不执行，返回 0，也符合定义。

#### 三、结论

$`S`$ 被划分成若干个互不相交的极大连续段，每段由唯一的段首代表。算法对每个段首准确算出整段长度（引理 1），而任何连续序列都不会比包含它的极大段更长（引理 2），所以取所有段首的最大值就是答案。Go `map` 的遍历顺序是随机的，但最大值与处理顺序无关，不影响结果。

另外，$`a_i \ge -10^9`$，所以 `num-1` 和 `currentNum+1` 都在 Go `int`（LeetCode 上为 64 位）的范围内，不会溢出。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为数组长度，$`m = |S| \le n`$ 为不同值的个数。下面的“期望”指散列表单次操作的期望 $`O(1)`$ 时间（见[总体笔记 §2.1](../README.zh-CN.md)）。

**时间复杂度：期望 O(n)**

- 建集合：$`n`$ 次插入，期望 $`O(n)`$。
- 外层循环：$`m`$ 次迭代，每次一次存在性查询，期望 $`O(m)`$。
- 内层循环：见下文的聚合分析，期望 $`O(m)`$。

如果逐次估计，一个段首的内层循环最多执行 $`m - 1`$ 次，乘以 $`m`$ 个外层迭代会得到 $`O(m^2)`$ 的松散上界。改用**聚合分析**统计内层循环在整个算法中一共执行多少次：内层循环只在段首处启动，段首 $`h`$ 处执行 $`L(h) - 1`$ 次，所以总次数为

```math
\sum_{h \text{ 是段首}} \bigl(L(h) - 1\bigr) = m - (\text{段首个数}) \le m
```

这里用到极大段互不相交、且覆盖整个 $`S`$，所以各段长度之和为 $`m`$。内层每执行一次做一次存在性查询，总计期望 $`O(m)`$。

合计期望 $`O(n + m) = O(n)`$。最坏情况下若散列严重冲突，单次操作可能退化为 $`\Theta(n)`$；Go 运行时为每个 `map` 使用随机的散列种子，这种情况在实践中不会被输入刻意触发。

**空间复杂度：O(n)**

散列集合保存 $`m \le n`$ 个不同值，额外空间 $`O(m) = O(n)`$；其余只有常数个变量。

## 5. 思维难点（Learning Notes）

### 难点一：双重循环为什么是 O(n)，不是 O(n²)？

代码在 `for` 循环里嵌了一个 `while`，看结构容易估成 $`O(n^2)`$。

**理解过程**

关键是段首条件 `!numSet[num-1]`。没有这个条件时，对段 `{1,2,3,4}` 会从 1、2、3、4 各扩展一次，总共 $`4 + 3 + 2 + 1`$ 步，长度为 $`m`$ 的段要 $`\Theta(m^2)`$ 步。加上条件后，只有 1 会启动扩展，2、3、4 被跳过，整段只扫一次。所以不能逐次估计内层循环，而要问“内层循环在整个算法中一共执行几次”：每个元素至多被它所在段的段首扫到一次，总数不超过 $`m`$。

**可迁移思维：** 嵌套循环的复杂度不一定是两层次数相乘。如果能找到一个量，使内层每执行一次就消耗掉一个“只能被消耗一次”的对象（这里是集合中的元素），就可以用聚合分析把总代价界定为对象总数。单调栈中“每个元素至多入栈、出栈各一次”是同一个论证。

### 难点二：为什么遍历集合而不是遍历原数组？

两种写法的答案相同，但复杂度不同。

**理解过程**

遍历原数组时，重复值会被多次处理。例如 `nums` 是 $`k`$ 个 1 后面跟上 $`1, 2, \ldots, k`$ 的段，那么段首 1 在原数组中出现 $`k+1`$ 次，每次都把整段扫一遍，内层循环总共执行约 $`k^2`$ 次，退化为 $`\Theta(n^2)`$。遍历集合时每个值只出现一次，段首也只启动一次扩展，才有上面的 $`O(n)`$ 上界。

**可迁移思维：** 用“每个对象只被处理一次”论证复杂度时，要确认被遍历的对象本身没有重复。输入可能含重复值时，先去重（这里由集合顺带完成）再做摊还分析。

### 难点三：为什么不直接排序？

排序后线性扫描也能求出答案，思路更直接，但时间是 $`O(n \log n)`$，不满足题目的 $`O(n)`$ 要求。

**理解过程**

排序提供的是全序信息，而本题只需要“$`x+1`$ 在不在”这种局部的存在性信息。散列集合正好以期望 $`O(1)`$ 回答这种查询，用 $`O(n)`$ 空间换掉了排序的对数因子。

**可迁移思维：** 当算法只依赖“某个值是否存在”，而不依赖元素之间的大小顺序时，可以考虑用散列集合代替排序。需要“比 $`x`$ 大的最小元素”这类有序查询时，散列表就不够用了。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Hash Set Membership（散列集合存在性查询）**：在本题中把“$`x+1`$ 在不在”降到期望 $`O(1)`$。适用于反复询问某个值是否出现过的问题；限制是只能回答存在性，不能回答有序查询，且只有期望而非最坏 $`O(1)`$。
2. **Run-Head Enumeration（段首枚举）**：在本题中只从 `x-1` 不在集合里的 `x` 出发扩展，使每段只被扫描一次。适用于答案由若干条互不相交的链构成、且链上的“前驱”可以 $`O(1)`$ 判断的问题，例如把“$`x \to x+1`$”换成“$`x \to x^2`$”的链。成立条件是链之间互不相交，每个元素只属于一条链。
3. **Aggregate Analysis（聚合分析）**：在本题中把内层循环的总次数界定为 $`m - (\text{段首个数})`$。适用于嵌套循环中内层每步都消耗一个只能被消耗一次的对象的情形，例如单调栈、双指针。
4. **Completeness via Maximality（用极大性证明完整性）**：引理 2 说明任何可行解都包含在某个极大段内，所以只需检查极大段。适用于“求满足某性质的最长结构”且该性质对子集封闭的问题。
