## 2. 题意理解（Problem Understanding）

给定平衡括号字符串 `s`，按下面三条规则计算分数：

1. `()` 得 1 分。
2. `AB` 得 $`A + B`$ 分，其中 `A`、`B` 是平衡括号字符串。
3. `(A)` 得 $`2A`$ 分，其中 `A` 是平衡括号字符串。

**示例**

- 输入：`s = "(()(()))"`
- 输出：`6`（里层 `()(())` 得 $`1 + 2 = 3`$，外面再套一层得 $`2 \times 3 = 6`$）

**关键要求**

1. 输入约束：$`2 \le n \le 50`$，`s` 只含 `(` 和 `)`，且是平衡括号字符串。
2. 规则 2 中的拆分方式可能不唯一（例如 `()()()`），但加法满足结合律，所以分数与拆分方式无关。
3. 边界：最深的输入是 25 层嵌套，分数为 $`2^{24}`$；一般地分数不超过 $`2^{n/2 - 1}`$（对文法归纳即得），Go 的 `int` 不会溢出。

## 4. 算法表达（Algorithm Specification）

### 4.0 共同定义

设 $`s = s_0 s_1 \cdots s_{n-1}`$，伪代码统一使用 **0-based** 索引。记 $`\mathrm{score}(A)`$ 为平衡串 $`A`$ 的分数，约定空串 $`\varepsilon`$ 的分数为 0。

**引理 0（非空平衡串的分数至少为 1）**：对文法归纳。`()` 得 1；`AB` 得 $`\mathrm{score}(A) + \mathrm{score}(B) \ge 2`$；`(A)` 得 $`2\,\mathrm{score}(A) \ge 2`$。

由此，对任意平衡串 $`B`$（可以为空），$`\mathrm{score}((B)) = \max(2\,\mathrm{score}(B), 1)`$：$`B`$ 为空时这是规则 1，非空时由引理 0 有 $`2\,\mathrm{score}(B) \ge 2 > 1`$，这是规则 3。

**前缀分解**：设 $`P`$ 是 $`s`$ 的一个前缀，$`d`$ 是 $`P`$ 中未匹配的左括号个数（即当前深度）。把这 $`d`$ 个未匹配左括号作为分隔符，$`P`$ 唯一地写成

```math
P = B_0 \, ( \, B_1 \, ( \, B_2 \cdots ( \, B_d
```

其中每个 $`B_k`$ 都是平衡串（可以为空）。$`B_k`$ 是第 $`k`$ 层里已经闭合的部分。

### 解法一：分层分数栈（Layered Score Stack）

#### 4.1 输入（Input）

平衡括号字符串 $`s`$，长度 $`n`$。

#### 4.2 输出（Output）

$`\mathrm{score}(s)`$。

#### 4.3 伪代码（Pseudocode）

```text
SCORE-STACK(s)
    st = [0]                       // st[0] 对应最外层
    for i = 0 to n - 1
        if s[i] == '('
            PUSH(st, 0)            // 打开新的一层
        else
            v = POP(st)            // 本层闭合，v = score(B_d)
            st[top] = st[top] + max(2v, 1)
    return st[0]
```

**状态定义**

- `st`：栈。处理完前缀 $`P`$ 后，`st[k]` 是 $`\mathrm{score}(B_k)`$，$`0 \le k \le d`$。
- `v`：刚闭合的那一层里已闭合部分的分数。

#### 4.4 正确性（Correctness）

**证明方法：循环不变式**

##### 一、正确性依赖的关键条件

1. **题目给定**：$`s`$ 是平衡串，所以读到 `)` 时 $`d \ge 1`$，POP 后栈非空，不会下溢。
2. **已证引理**：引理 0 及其推论 $`\mathrm{score}((B)) = \max(2\,\mathrm{score}(B), 1)`$。
3. **规则 2**：拼接的分数相加。

##### 二、正确性证明

**循环不变式**：第 $`i`$ 次迭代开始时，设已处理前缀 $`P = s_0 \cdots s_{i-1}`$ 的分解为 $`B_0 ( B_1 \cdots ( B_d`$，则栈长度为 $`d + 1`$，且对 $`0 \le k \le d`$ 有 `st[k]` $`= \mathrm{score}(B_k)`$。

**初始化**：$`i = 0`$ 时 $`P = \varepsilon`$，$`d = 0`$，$`B_0 = \varepsilon`$，`st = [0]`，成立。

**保持**：

- $`s_i =`$ `(`：新前缀为 $`B_0 ( \cdots ( B_d ( \varepsilon`$，深度变为 $`d + 1`$，新的最内层已闭合部分为空。算法压入 0，前 $`d + 1`$ 个元素不变，不变式成立。
- $`s_i =`$ `)`：由条件 1 有 $`d \ge 1`$。这个 `)` 匹配第 $`d`$ 个未匹配左括号，新前缀为 $`B_0 ( \cdots ( B_{d-1} ( B_d )`$，深度变为 $`d - 1`$，第 $`d - 1`$ 层的已闭合部分变成 $`B_{d-1} ( B_d )`$。由规则 2 和推论，它的分数是 $`\mathrm{score}(B_{d-1}) + \max(2\,\mathrm{score}(B_d), 1)`$。算法弹出 $`v = \mathrm{score}(B_d)`$，再把 $`\max(2v, 1)`$ 加到新栈顶 `st[d-1]` 上，正好得到这个值；其余元素不变。不变式成立。

**终止**：循环恰好执行 $`n`$ 次。结束时 $`P = s`$，因为 $`s`$ 平衡，$`d = 0`$，分解只剩 $`B_0 = s`$，于是 `st[0]` $`= \mathrm{score}(s)`$。

##### 三、结论

对任意平衡括号串，栈不会下溢，返回值等于 $`\mathrm{score}(s)`$。

#### 4.5 复杂度分析（Complexity Analysis）

设 $`n = |s|`$，$`D`$ 为 $`s`$ 的最大嵌套深度，$`1 \le D \le n/2`$。

**时间复杂度：$`\Theta(n)`$**。每个字符做一次 PUSH 或一次 POP 加一次加法。按[总体笔记](../README.zh-CN.md#22-go-中的写法) 2.2 节，`append` 摊还 $`O(1)`$，总时间 $`\Theta(n)`$。

**空间复杂度：$`O(D)`$，最坏 $`O(n)`$**。栈长度始终是 $`d + 1 \le D + 1`$；`s` 为 $`n/2`$ 层完全嵌套时达到 $`n/2 + 1`$。

### 解法二：深度贡献求和（Depth Contribution Sum）

#### 4.1 输入与输出

同解法一。

#### 4.2 核心引理

称 $`s_j s_{j+1} =`$ `()` 为一个**原子对**，记 $`d_j`$ 为位置 $`j`$ 之前未匹配左括号的个数，即包住这个原子对的层数。

**引理 1（贡献公式）**：对任意非空平衡串 $`A`$，

```math
\mathrm{score}(A) = \sum_{\text{原子对 } j} 2^{d_j}
```

**证明**（对文法结构归纳）：

- `()`：唯一的原子对在深度 0，和为 $`2^0 = 1`$。
- `AB`：$`A`$ 非空平衡，以 `)` 结尾；$`B`$ 以 `(` 开头。交界处是 `)(`，不产生新原子对。$`A`$ 结束时深度回到 0，所以 $`B`$ 中每个原子对的深度不变。和等于两部分之和，与规则 2 一致。
- `(A)`：外层 `(` 后面是 $`A`$ 的首字符 `(`，$`A`$ 的末字符 `)` 后面是外层 `)`，都不构成原子对。$`A`$ 中每个原子对的深度加 1，贡献乘 2。由分配律，和变为原来的 2 倍，与规则 3 一致。

直观地说，这就是把 $`2A`$ 中的 2 用分配律乘进 $`A`$ 的每一项，一直展开到原子对为止。

#### 4.3 伪代码（Pseudocode）

```text
SCORE-DEPTH(s)
    res = 0
    depth = 0
    for i = 0 to n - 1
        if s[i] == '('
            depth = depth + 1
        else
            depth = depth - 1
            if s[i - 1] == '('     // s[i-1] s[i] 是原子对
                res = res + 2^depth
    return res
```

**状态定义**

- `depth`：已处理前缀中未匹配左括号的个数。
- `res`：已处理前缀中完整原子对的贡献之和。

读到 `)` 时 $`i \ge 1`$（平衡串首字符必为 `(`），所以 `s[i-1]` 合法。

#### 4.4 正确性（Correctness）

**证明方法：引理 1 + 循环不变式**

**循环不变式**：第 $`i`$ 次迭代开始时，`depth` 等于前缀 $`s_0 \cdots s_{i-1}`$ 中未匹配左括号的个数，`res` 等于完全落在这个前缀里的原子对的贡献之和。

**初始化**：空前缀，两者都是 0，成立。

**保持**：

- $`s_i =`$ `(`：深度加 1，不会形成以 $`i`$ 结尾的原子对，`res` 不变。成立。
- $`s_i =`$ `)` 且 $`s_{i-1} =`$ `)`：深度减 1，没有新原子对。成立。
- $`s_i =`$ `)` 且 $`s_{i-1} =`$ `(`：$`(i-1, i)`$ 是新原子对。读 $`s_{i-1}`$ 之前深度为 $`d_{i-1}`$，读完 `(` 变为 $`d_{i-1} + 1`$，再减 1 回到 $`d_{i-1}`$。所以此时累加的 $`2^{\mathrm{depth}}`$ 正是 $`2^{d_{i-1}}`$。成立。

**终止**：循环执行 $`n`$ 次后，`res` 是 $`s`$ 中全部原子对的贡献之和，由引理 1 等于 $`\mathrm{score}(s)`$。

#### 4.5 复杂度分析（Complexity Analysis）

**时间复杂度：$`\Theta(n)`$**，每个字符 $`O(1)`$。

**空间复杂度：$`O(1)`$**，只用 `res`、`depth` 两个整数。

### 两种解法的关系

解法二**不是**把解法一的栈压缩成计数器。解法一的栈里每层存的分数各不相同，栈的内容不能只由长度决定。解法二换了一种计算方式：用引理 1 把答案改写成只依赖深度的形式，所以只需要记深度。见[总体笔记](../README.zh-CN.md#4-什么时候可以不用栈)第 4 节的两种情况。

## 5. 思维难点（Learning Notes）

### 难点一：`()` 的分数为什么是 $`\max(2v, 1)`$

规则 1 和规则 3 看起来是两条规则，用栈实现时却合成了一个表达式。关键在于引理 0：非空平衡串分数至少为 1，所以 $`v = 0`$ 当且仅当本层里什么也没有，这时得 1；否则得 $`2v`$。

**可迁移思维：** 把空串的值约定为运算的单位元（这里是加法的 0），常能把“空”与“非空”两个分支合并成一个式子。

### 难点二：深度解法为什么只看原子对

只有规则 1 产生新的分数，规则 2 和规则 3 只是对已有分数做加法和乘 2。把乘 2 用分配律一层层推到最里面，每个原子对就带上了 $`2^{\text{深度}}`$ 的系数。

**可迁移思维：** 当结果由“基本单元 + 线性组合规则”递归生成时，可以把结果拆成每个基本单元的贡献之和，贡献的系数等于从根到该单元路径上所有乘数之积。

## 6. 可迁移知识（Key Takeaways）

1. **Layered Partial Sums on a Stack（栈中分层部分和）**
   - 本题作用：每个未闭合的层在栈中有一个累加器，闭合时把本层结果折算后并入外层。
   - 适用问题：递归定义的嵌套结构求值，如带括号的表达式、嵌套列表的加权和。
   - 成立条件：外层结果只依赖里层的汇总值，不依赖里层的内部结构。
2. **Structural Induction（结构归纳）**
   - 本题作用：沿文法的三条产生式证明引理 0 和引理 1。
   - 适用问题：对象由文法或递归规则生成，要证明的性质对每条规则都能保持。
   - 成立条件：每个对象都能由规则有限步生成；拼接规则不唯一时，要说明结论不依赖拆分方式。
3. **Contribution Technique（贡献法）**
   - 本题作用：把总分改写为各原子对贡献 $`2^{d}`$ 之和，从而只需记录深度。
   - 适用问题：答案可以写成若干基本单元贡献之和，且每个单元的贡献能在局部算出。
   - 成立条件：组合规则对贡献是线性的（这里依赖乘法对加法的分配律）；规则含 max、min 等非线性运算时一般不成立。
