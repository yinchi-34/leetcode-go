## 2. 题意理解（Problem Understanding）

给定整数 `numRows`，返回杨辉三角的前 `numRows` 行。杨辉三角中，每行两端是 1，其余每个数等于它上一行左上方与右上方两个数之和。

**示例**

- 输入：`numRows = 5`
- 输出：`[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

**关键要求**

1. 输入约束：$`1 \le \mathrm{numRows} \le 30`$。
2. 输出是一个二维数组，第 $`i`$ 行（从 0 开始计）恰有 $`i+1`$ 个数。
3. 边界：`numRows = 1` 时只返回 `[[1]]`；第 0 行和第 1 行没有“中间元素”，全部由两端的 1 构成。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 逐行递推（Row-by-Row Recurrence）

本节行号与列号均从 0 开始。

### 4.1 输入（Input）

一个正整数 $`n = \mathrm{numRows}`$，满足 $`1 \le n \le 30`$。

### 4.2 输出（Output）

输出 $`n`$ 行数组 $`R_0, R_1, \ldots, R_{n-1}`$，其中 $`R_i = \langle R_i[0], \ldots, R_i[i] \rangle`$ 的长度为 $`i+1`$。

题目规则把杨辉三角定义为满足以下递推的数表 $`P`$：

```math
P(i, j) =
\begin{cases}
1, & j = 0 \text{ 或 } j = i \\
P(i-1, j-1) + P(i-1, j), & 0 < j < i
\end{cases}
```

输出必须满足：对所有 $`0 \le i < n`$、$`0 \le j \le i`$，都有 $`R_i[j] = P(i, j)`$。

### 4.3 伪代码（Pseudocode）

```text
GENERATE(n)
    res ← 长度为 n 的数组，每个元素是一行
    for i ← 0 to n - 1
        res[i] ← 长度为 i + 1 的新数组
        for j ← 0 to i
            if j == 0 or j == i
                res[i][j] ← 1
            else
                res[i][j] ← res[i-1][j] + res[i-1][j-1]
    return res
```

**状态定义**

- `res[i]`：杨辉三角的第 `i` 行。外层循环处理第 `i` 行时，`res[0..i-1]` 已全部填好，此后不再修改。
- `i`：当前正在生成的行号，也是该行最后一个元素的下标。
- `j`：当前行中正在填写的列号。

### 4.4 正确性（Correctness）

**证明方法：外层循环不变式 + 内层逐项检查**

#### 一、正确性依赖的关键条件

1. **递推定义（题目给定）**：$`P(i, j)`$ 由 4.2 的递推唯一确定。第 $`i`$ 行只依赖第 $`i-1`$ 行，因此按行号从小到大计算时，所需的值总是已经算出。
2. **下标合法性（待证引理）**：进入 `else` 分支时，`res[i-1][j-1]` 和 `res[i-1][j]` 都在第 $`i-1`$ 行的范围内。
3. **行之间互不共享存储（实现事实）**：每行用 `make` 单独分配，写第 $`i`$ 行不会改动已完成的行。

**引理（下标合法性）**：`else` 分支的条件是 $`j \ne 0`$ 且 $`j \ne i`$，结合 $`0 \le j \le i`$ 得 $`1 \le j \le i-1`$。这要求 $`i \ge 2`$，因此 $`i-1 \ge 1`$，第 $`i-1`$ 行存在。又因为第 $`i-1`$ 行的合法下标是 $`0 \ldots i-1`$，而 $`0 \le j-1`$ 且 $`j \le i-1`$，所以两个下标都合法。特别地，$`i = 0`$ 和 $`i = 1`$ 时内层循环只走 `if` 分支，不会访问不存在的 `res[-1]`。

#### 二、正确性证明

**循环不变式（Loop Invariant）**

外层循环每次迭代开始时（即将处理第 $`i`$ 行）：

**不变式 I：已完成的行正确**

对所有 $`0 \le r < i`$，`res[r]` 的长度为 $`r+1`$，且 `res[r][j]` $`= P(r, j)`$ 对 $`0 \le j \le r`$ 成立。

**初始化（Initialization）**

$`i = 0`$ 时，没有已完成的行，不变式 I 空真成立。

**保持（Maintenance）**

假设处理第 $`i`$ 行之前不变式 I 成立。算法先分配长度为 $`i+1`$ 的新行，再对每个 $`j \in \{0, \ldots, i\}`$ 写入一次：

- **情况一：$`j = 0`$ 或 $`j = i`$**。写入 1，与 $`P(i, j)`$ 的定义一致。
- **情况二：$`0 < j < i`$**。由引理，两个下标都合法；由不变式 I，`res[i-1][j-1]` $`= P(i-1, j-1)`$，`res[i-1][j]` $`= P(i-1, j)`$。写入二者之和，正好是 $`P(i, j)`$。

由关键条件 3，写第 $`i`$ 行不会改变 `res[0..i-1]`。因此第 $`i`$ 行结束后，对所有 $`r < i+1`$ 不变式 I 仍成立。

**终止（Termination）**

外层循环恰好执行 $`n`$ 次，每次内层循环恰好执行 $`i+1`$ 次，均有限，算法必然终止。终止时 $`i = n`$，由不变式 I，`res[0..n-1]` 正是杨辉三角的前 $`n`$ 行。

#### 三、结论

对任意 $`1 \le n \le 30`$，算法返回的每一行长度正确，每个元素都等于题目递推定义的值，所以算法正确。

**补充：数值不会溢出。** 可以证明 $`P(i, j) = \binom{i}{j}`$（见第 5 节难点二），因此结果中的最大值是 $`\binom{29}{14} = 77\,558\,760`$，小于 $`2^{31}-1`$。即使 `int` 只有 32 位也不会溢出。这条结论只用于说明数值范围，上面的正确性证明并不依赖它。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n = \mathrm{numRows}`$。

**时间复杂度：$`\Theta(n^2)`$**

第 $`i`$ 行写入 $`i+1`$ 个元素，每次写入是常数时间，总写入次数为：

```math
\sum_{i=0}^{n-1} (i+1) = \frac{n(n+1)}{2}
```

所以时间为 $`\Theta(n^2)`$。$`n = 30`$ 时共写 465 个数。输出本身就有 $`n(n+1)/2`$ 个数，任何算法至少要逐个写出它们，所以对本题来说 $`\Omega(n^2)`$ 是无法绕过的下界，本算法在渐近意义上已经达到它。

**空间复杂度：$`\Theta(n^2)`$（计入输出）**

返回的二维数组共 $`n(n+1)/2`$ 个整数，外加 $`n`$ 个切片头。

不计输出时，额外空间只有循环变量 `i`、`j`，为 $`O(1)`$。

## 5. 思维难点（Learning Notes）

### 难点一：为什么 `i = 0` 和 `i = 1` 时不会访问 `res[i-1]`？

代码中 `res[i-1]` 看起来在 `i = 0` 时会越界，但实际上从未执行。

**理解过程**

是否读取上一行，由 `j == 0 || j == i` 这个条件决定。第 0 行只有 $`j = 0`$，第 1 行只有 $`j = 0`$ 和 $`j = 1 = i`$，全部落在两端，走 `if` 分支。只有 $`i \ge 2`$ 时才会出现 $`0 < j < i`$ 的中间位置，此时上一行一定存在。也就是说，“两端是 1”这条规则不仅给出了边界值，也恰好保护了下标。

**可迁移思维：** 写递推时，先确认“递推分支被触发的条件”能推出“被引用的状态已存在且下标合法”。能推出就不需要额外特判；推不出就要补一个基础情况。

### 难点二：杨辉三角和组合数是什么关系？

题目只给出加法规则，但它的每个数正好是二项式系数 $`\binom{i}{j}`$。

**理解过程**

只需证明 $`\binom{i}{j}`$ 满足与 $`P`$ 相同的边界和递推，再对 $`i`$ 归纳即可得到两者处处相等。

- 边界：$`\binom{i}{0} = \binom{i}{i} = 1`$。
- 递推（帕斯卡法则）：从 $`\{1, \ldots, i\}`$ 中选 $`j`$ 个元素，按“是否选了元素 $`i`$”分成两类，不重不漏。选了 $`i`$ 的，剩下 $`j-1`$ 个从前 $`i-1`$ 个里选，有 $`\binom{i-1}{j-1}`$ 种；没选 $`i`$ 的，$`j`$ 个都从前 $`i-1`$ 个里选，有 $`\binom{i-1}{j}`$ 种。

```math
\binom{i}{j} = \binom{i-1}{j-1} + \binom{i-1}{j}, \qquad 0 < j < i
```

两者边界相同、递推相同，按行归纳可得 $`P(i, j) = \binom{i}{j}`$。这个结论给出了第 4.4 节的溢出上界，也说明第 $`i`$ 行可以不依赖上一行，直接用 $`\binom{i}{j} = \binom{i}{j-1} \cdot \frac{i-j+1}{j}`$ 逐项算出。

**可迁移思维：** 遇到一个只用加法规则定义的数表时，可以问一句它是否在“数某种方案”。如果能找到计数解释，就能得到封闭形式、取值范围和新的计算方法。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Bottom-Up Tabulation（自底向上填表）**：在本题中，第 $`i`$ 行只依赖第 $`i-1`$ 行，按行号递增计算就保证依赖先于使用。适用于状态之间存在明确拓扑顺序的递推和动态规划问题。前提是计算顺序必须是依赖关系的一个拓扑序。
2. **Loop Invariant（循环不变式）**：在本题中，“前 $`i`$ 行已经正确”这一不变式把整张表的正确性拆成逐行检查。适用于逐行、逐列或逐段构造结果的模拟题。不变式需要说清在循环的哪个时刻成立，本题取外层循环开始时。
3. **Pascal's Rule（帕斯卡法则）**：在本题中，它把加法规则和组合数 $`\binom{i}{j}`$ 联系起来，给出数值上界。适用于路径计数、子集计数和二项展开系数等问题。用组合数的封闭形式时，要注意乘法过程中的中间值溢出和整除顺序。
4. **Rolling Array（滚动数组）**：本题要求返回所有行，所以必须保留整张表；如果只需要最后一行（如 119 题），每一行只依赖上一行，可以只保留一维数组，并从右往左更新，避免先被覆盖的 `row[j-1]` 再被读取。这一点只在“只需最后一层”时成立。
