## 2. 题意理解（Problem Understanding）

给定整数数组 `nums`，可以将元素**以任意顺序重新排列**，得到数组 `arr`。其交替得分定义为：

$$
score = arr_0^2 - arr_1^2 + arr_2^2 - arr_3^2 + \cdots
$$

求重排后可能的最大交替得分。

例如：

- `[1,2,3]`：重排为 `[2,1,3]`，得分 `4 - 1 + 9 = 12`。
- `[1,-1,2,-2,3,-3]`：最大得分为 `16`。

关键约束：

1. 可以任意重排，原始顺序没有任何意义。
2. 偶数下标取正号，奇数下标取负号。
3. 元素可以为负数，`-4·10^4 ≤ nums[i] ≤ 4·10^4`。
4. `1 ≤ n ≤ 10^5`。

### 核心问题

本题并不是要寻找某种精巧的排列方式。

由于可以任意重排，**真正需要决定的只有：哪些元素放在加号位置，哪些元素放在减号位置。**

至于加号位置内部、减号位置内部如何排列，得分完全相同。

因此：

**这是一个分组问题，而不是一个排列问题。**

## 3. 初始思路（Initial Approach）

### 3.1 第一版：取绝对值后显式分成两组

最初的想法很直接：绝对值越大，平方越大，越应该放在加号位置。

```text
MAX-ALTERNATING-SUM-V1(nums)
    n ← length(nums)
    for i ← 0 to n - 1
        d[i] ← |nums[i]|

    SORT-DESC(d)                         // 降序

    if n mod 2 == 0
        plus   ← d[0 .. n/2 - 1]         // 前 n/2 个
        minus  ← d[n/2 .. n - 1]
    else
        plus   ← d[0 .. ⌊n/2⌋]           // 前 ⌊n/2⌋ + 1 个
        minus  ← d[⌊n/2⌋ + 1 .. n - 1]

    return Σ_{x ∈ plus} x² − Σ_{y ∈ minus} y²
```

这一版的思路是正确的：

- 用绝对值排序，与用平方值排序得到的顺序一致（$`|x|`$ 与 $`x^2`$ 同增同减）。
- 降序排序后，前 ⌈n/2⌉ 个放入加组，其余放入减组。

但实现上有几处多余：

- 需要按 n 的奇偶分两个分支，分别计算切分位置。
- 额外构造了 `plus` 和 `minus` 两个列表。
- 先取绝对值、最后再平方，变换分成了两步。

### 3.2 思维转变：用一个分界点统一奇偶

重新观察两个分支：

- n 为偶数：加组 n/2 个，减组 n/2 个。
- n 为奇数：加组 (n+1)/2 个，减组 (n−1)/2 个。

两种情况下，**减组的大小始终是 ⌊n/2⌋**，加组自然就是剩下的 ⌈n/2⌉ 个。

所以改为**升序**排序平方值，令：

$$
k = \lfloor n/2 \rfloor
$$

则 `sq[:k]` 是减组，`sq[k:]` 是加组，奇偶两种情况被同一个分界点覆盖：

```text
n = 3：k = 1
  sq[:1] → 减（1 个）
  sq[1:] → 加（2 个 = ⌈3/2⌉）

n = 4：k = 2
  sq[:2] → 减（2 个）
  sq[2:] → 加（2 个 = ⌈4/2⌉）
```

简化后的实现：

```text
MAX-ALTERNATING-SUM-V2(nums)
    n ← length(nums)
    for i ← 0 to n - 1
        a[i] ← nums[i]²

    SORT(a)                              // 升序
    k ← ⌊n/2⌋                            // 分界点 = 减组大小

    return Σ_{i=k}^{n-1} a[i] − Σ_{i=0}^{k-1} a[i]
```

### 思维转变总结

从：

> 按 n 的奇偶，分别算出加组和减组各取多少个。

转变为：

> 排序后两组分别是前缀和后缀，只需要确定一个分界点。

前者关注"每组有多少个"，后者关注"分界在哪里"。

**核心认知：排序后的分组问题，往往可以归结为找一个分界点；选好分界点的定义（取较小那组的大小 ⌊n/2⌋），就能消除奇偶分支。**

## 4. 算法表达（Algorithm Specification）

**算法名称：** 贪心（Greedy）

### 4.1 输入（Input）

输入一个长度为 n 的整数数组：

$$
nums = \langle x_0, x_1, \ldots, x_{n-1} \rangle
$$

**前置条件：**

- **长度约束**：$`1 \leq n \leq 10^5`$。
- **取值约束**：$`-4 \times 10^4 \leq x_i \leq 4 \times 10^4`$。
- **顺序约束**：无，允许任意重排。

### 4.2 输出（Output）

输出一个整数 `k`，表示重排后的最大交替得分。

设 $`S_n`$ 为 $`\{0, 1, \ldots, n-1\}`$ 上所有排列的集合，则目标为：

$$
\text{OPT} = \max_{\sigma \in S_n} \sum_{j=0}^{n-1} (-1)^j \, x_{\sigma(j)}^2
$$

等价的分组形式：设 $`P`$ 为加组下标集合，满足 $`|P| = p = \lceil n/2 \rceil`$，$`a_i = x_i^2`$，$`T = \sum_i a_i`$，则：

$$
\text{OPT} = \max_{|P| = p} \left( \sum_{i \in P} a_i - \sum_{i \notin P} a_i \right)
  = \max_{|P| = p} \left( 2\sum_{i \in P} a_i - T \right)
$$

由于 $`T`$ 是常数，**最大化得分等价于最大化加组之和。**

### 4.3 伪代码（Pseudocode）

```text
MAX-ALTERNATING-SUM(nums)
    n ← length(nums)

    for i ← 0 to n - 1
        a[i] ← nums[i] * nums[i]

    SORT(a)                      // 升序
    k ← ⌊n/2⌋                    // 减组大小

    res ← 0
    for i ← 0 to n - 1
        if i ≥ k
            res ← res + a[i]     // 较大的 ⌈n/2⌉ 个：加号位置
        else
            res ← res - a[i]     // 较小的 ⌊n/2⌋ 个：减号位置

    return res
```

**状态定义**

- `a[i]`：第 i 个元素的平方值（Go 实现中原地覆盖 `nums[i]`）。
- `k`：减号位置的数量，也是排序后加组的起始下标。
- `res`：当前累计的交替得分，使用 `int64`。

**输入修改（Go）**

`maxAlternatingSum` 会先将 `nums` 中的元素原地替换为平方值，再升序排序，从而修改调用方的切片。要保留输入，请先复制切片（如 `append([]int(nil), nums...)`），再将副本传入。

**贪心策略**

平方值越大的元素越应该放在加号位置；平方值越小的元素越应该放在减号位置。

### 4.4 构造方案（Construction）

算法只计算分数，但可以显式给出达到该分数的排列：

1. 升序排序后，令加组为 $`a_{k}, \ldots, a_{n-1}`$，减组为 $`a_0, \ldots, a_{k-1}`$。
2. 将加组元素依次放入下标 0, 2, 4, …；将减组元素依次放入下标 1, 3, 5, …。

加组恰有 p 个元素、偶数下标恰有 p 个，减组同理，因此构造总是可行的。

例如 `[1,2,3]`：平方后为 `[1,4,9]`，k = 1，加组 `{4, 9}`，减组 `{1}`，构造出 `[2,1,3]`，得分 12。

### 4.5 正确性（Correctness）

**证明方法：循环不变式（求值正确）+ 上界论证（全局最优）**

> **上界论证是不是贪心？** 不是。贪心是算法的选择策略："平方值大的放加号位置"。上界论证是证明这个策略最优的方法：证明任何方案的得分都不可能超过贪心给出的值。它对应 1541 第四部分"为什么是全局最优"中的下界论证；1541 是最小化，所以证下界，本题是最大化，所以证上界。交换论证是证明贪心最优的另一种常用方法，见第四部分末尾。

#### 一、关键性质

**性质 A：得分只取决于分组**

得分为：

$$
\sum_{j \text{ 偶}} a_{\sigma(j)} - \sum_{j \text{ 奇}} a_{\sigma(j)}
$$

交换两个偶数下标上的元素，或交换两个奇数下标上的元素，两个求和都不变。因此得分只由加组集合 $`P`$ 决定。

反过来，对任意满足 $`|P| = p`$ 的集合，按 4.4 的方式都能构造出对应排列。所以排列问题与分组问题**完全等价**。

**性质 B：加号位置恰有 ⌈n/2⌉ 个**

下标从 0 开始，偶数下标为加号：

$$
p = \lceil n/2 \rceil = n - \lfloor n/2 \rfloor,\qquad q = k = \lfloor n/2 \rfloor
$$

所以任何合法分组都满足 $`|P| = p`$，减组大小恰为 $`k`$。

**性质 C：最大化差等价于最大化加组之和**

$$
\text{score}(P) = 2\sum_{i \in P} a_i - T
$$

$`T`$ 与分组无关，因此得分随加组之和单调递增。

#### 二、循环不变式

设平方值已升序排列为 $`a_0 \le a_1 \le \cdots \le a_{n-1}`$，$`k = \lfloor n/2 \rfloor`$。

在处理完前 $`i`$ 个元素后：

**不变式 I（累计值）**

$$
res = \sum_{j=0}^{i-1} c_j \, a_j,\qquad
c_j =
\begin{cases}
-1, & j < k \\
+1, & j \ge k
\end{cases}
$$

**不变式 II（分组合法）**

已处理的元素中，被取负的恰为其中最小的 $`\min(i, k)`$ 个，且总数不超过 $`k`$；被取正的不超过 $`p`$ 个。

#### 三、正确性证明（Proof）

**1. 初始化（Initialization）**

$`i = 0`$ 时，$`res = 0`$，没有处理任何元素，两个不变式都成立。

**2. 保持（Maintenance）**

处理第 $`i`$ 个元素时：

- 若 $`i < k`$：执行 `res -= a[i]`，对应 $`c_i = -1`$。此前取负的元素数为 $`i < k`$，加上当前元素后为 $`i + 1 \le k`$，不超过减组容量。
- 若 $`i \ge k`$：执行 `res += a[i]`，对应 $`c_i = +1`$。取正元素数为 $`i - k + 1 \le n - k = p`$，不超过加组容量。

由于数组升序，前 $`k`$ 个始终是最小的元素。两个不变式继续成立。

**3. 终止（Termination）**

$`i = n`$ 时：

$$
res = \sum_{j=k}^{n-1} a_j - \sum_{j=0}^{k-1} a_j
$$

加组 $`P_g = \{k, \ldots, n-1\}`$ 恰有 $`n - k = p`$ 个元素，是一个合法分组。由性质 A 和 4.4 的构造，存在一个排列恰好取得这个得分，所以：

$$
\text{OPT} \ge res
$$

到这里只说明了算法的结果**可以达到**，还需要说明它**不能被超过**。

#### 四、为什么是全局最优？

**上界论证**

对任意满足 $`|P| = p`$ 的分组，加组之和不可能超过"最大的 p 个平方值之和"：

$$
\sum_{i \in P} a_i \le \sum_{j=k}^{n-1} a_j
$$

由性质 C：

$$
\text{score}(P) = 2\sum_{i \in P} a_i - T
\;\le\; 2\sum_{j=k}^{n-1} a_j - T
= res
$$

所以任何排列的得分都不超过 $`res`$：

$$
\text{OPT} \le res
$$

结合第三部分的 $`\text{OPT} \ge res`$：

$$
\text{OPT} = res
$$

**因此，算法得到全局最大交替得分。**

**另一种证明视角：交换论证**

任取一个最优分组 $`P^*`$。若它不是"最大的 p 个"，则存在 $`i \in P^*`$、$`j \notin P^*`$，使得 $`a_i < a_j`$。交换二者的组别，得分变化为：

$$
\Delta = 2(a_j - a_i) > 0
$$

与 $`P^*`$ 最优矛盾。所以最优分组的加组必然是最大的 p 个（平方值相等时交换不改变得分，不影响结论）。

**为什么必须按平方值排序？**

上界论证中比较的是 $`a_i = x_i^2`$。当数组含负数时，$`x_i < x_j`$ 并不意味着 $`x_i^2 < x_j^2`$，所以排序关键字必须是平方值或绝对值。Go 实现中先执行 `nums[i] *= nums[i]` 再 `sort.Ints(nums)`，排序关键字自然就是平方值。

**这个证明与直觉的对应**：性质 A 对应"重排后只剩分组"，性质 B 对应"分界点取 ⌊n/2⌋"，上界论证对应"大的放加号"。三者合起来，说明不存在比"排序后切一刀"更好的方案。

### 4.6 复杂度分析（Complexity Analysis）

设输入数组长度为 n。

**时间复杂度：O(n log n)**

- 平方变换：O(n)。
- 排序：O(n log n)。
- 累加：O(n)。

$$
T(n) = O(n \log n)
$$

**额外空间复杂度：O(log n)**

- Go 实现中平方值原地覆盖 `nums`，不额外分配数组。
- `sort.Ints` 使用 pdqsort，递归栈深度为 O(log n)。

$$
S(n) = O(\log n)
$$

Python 版本中 `sorted` 会新建列表，额外空间为 O(n)。

**数值范围：**

- 单个平方值最大为 $`(4 \times 10^4)^2 = 1.6 \times 10^9`$，接近 32 位有符号整数上限 $`2^{31} - 1 \approx 2.147 \times 10^9`$，两个相加就会溢出 int32。
- 累加绝对值上界为 $`10^5 \times 1.6 \times 10^9 = 1.6 \times 10^{14}`$，在 int64 范围内。
- LeetCode 的 Go 环境中 `int` 为 64 位，`nums[i] *= nums[i]` 不会溢出；结果累加使用 `int64` 与函数签名一致。

### 4.7 可选优化：线性时间

排序并不是必需的，只需要找出最大的 p 个平方值：

1. **快速选择（Quickselect）**：找出第 k 小的平方值作为分界点，期望 O(n)。
2. **计数排序**：$`|x_i| \leq 4 \times 10^4`$，按绝对值计数，时间 O(n + V)，空间 O(V)，其中 V = 4·10⁴。

在本题规模下，O(n log n) 的排序已经足够，优化主要用于理解"只需要分界点，不需要全序"。

## 5. 思维难点（Learning Notes）

### 难点一：为什么"可以任意重排"是关键？

因为任意重排使得原始顺序完全失去意义。

一旦意识到这一点，就不必思考"如何构造排列"，只需思考"如何分组"。

对比 [1911. 最大子序列交替和](https://leetcode.cn/problems/maximum-alternating-subsequence-sum/)：子序列必须保持原顺序，因此需要动态规划；而本题顺序自由，贪心即可。

**可迁移思维：遇到"可以任意重排 / 任意交换"的条件，先检查问题是否退化为多重集合上的选择问题。**

### 难点二：为什么要按平方值排序，而不是原值？

因为得分只由平方值决定，而负数会让原值顺序与平方值顺序不一致。

例如 `[-5, 1, 2]`：

```text
按原值升序：[-5, 1, 2]
  n = 3，k = 1，减组：-5 → 减去 25
  加组：1, 2 → 加上 1 + 4
  得分：5 - 25 = -20     ✗

按平方值升序：[1, 4, 25]
  减组：1
  加组：4, 25
  得分：29 - 1 = 28      ✓
```

用绝对值排序（第一版的做法）同样正确，因为 $`|x|`$ 与 $`x^2`$ 的大小顺序一致。

**可迁移思维：贪心比较的必须是真正影响目标函数的量。先把输入变换成"贡献值"，再做贪心。**

### 难点三：为什么分界点是 `n // 2`？

关键在于加号位置比减号位置多还是一样多。

- 下标从 0 开始，偶数下标为加号。
- 偶数下标共有 ⌈n/2⌉ 个，奇数下标共有 ⌊n/2⌋ 个。

升序排序后，前 ⌊n/2⌋ 个进入减组，即 `sq[:k]`；其余进入加组，即 `sq[k:]`。

第一版按奇偶写了两个分支，本质上就是在分别计算 ⌈n/2⌉。改为用较小一组的大小 ⌊n/2⌋ 作为分界点后，两种情况自动统一。

如果误写成 `k = (n+1)//2`，在 n 为奇数时会把一个本该加上的元素减掉。

**可迁移思维：处理"一半"时，先明确奇数情况下多出来的那个元素归哪一边，再选择不需要分支的分界点定义。**

## 6. 可迁移知识（Key Takeaways）

### 6.1 自由重排 ⇒ 位置退化为计数

当元素可以任意排列，而目标函数只依赖"每个位置属于哪一类"时：

> 位置信息可以压缩为"每一类位置各有多少个"。

本题把 n 个位置压缩为"p 个加号位置、k 个减号位置"。

适用于：

- 将元素分配到若干类槽位的最优化问题。
- 带系数的重排求和问题（如排序不等式类问题）。

### 6.2 目标函数线性化：最大化差 ⇔ 最大化一侧

$$
\sum_{P} a - \sum_{\bar P} a = 2\sum_{P} a - T
$$

总和固定时，"最大化两组之差"等价于"最大化其中一组之和"。

这一技巧常用于分组、划分、正负号分配类问题。

### 6.3 贪心最优性的两种证明：上界论证与交换论证

贪心是选择策略，最优性需要单独证明。常用两种方法：

**上界（下界）论证**

1. 证明贪心结果可以达到（构造出一个合法方案）。
2. 证明任何合法方案都不会比贪心更好（最大化证上界，最小化证下界）。
3. 二者相等，即为最优。

**交换论证**

1. 假设存在一个与贪心不同的最优解。
2. 找到一对"顺序不对"的元素。
3. 证明交换后结果不变差。
4. 反复交换，最终变成贪心解。

本题两种方法都很直接：上界来自"最大的 p 个之和"，交换收益为 $`2(a_j - a_i)`$。1541 使用的是下界论证。

### 6.4 先变换，再贪心

当目标函数中元素以 $`f(x)`$ 的形式出现时，贪心比较的对象应是 $`f(x)`$（或与其顺序一致的量），而不是 $`x`$。

本题中 $`f(x) = x^2`$，在含负数时关于 $`x`$ 不单调，但关于 $`|x|`$ 单调，所以按平方值或绝对值排序都可以。

### 6.5 与 1911 的联系

| 对比维度 | 1911. 最大子序列交替和 | 3727. 最大交替平方和 |
|---|---|---|
| 可选操作 | 选子序列，保持原顺序 | 全部元素任意重排 |
| 元素贡献 | 原值 | 平方值 |
| 位置是否重要 | 重要，下标奇偶依赖已选元素个数 | 不重要，只需知道加减位置数 |
| 核心建模 | 状态机 DP（下一个取正还是取负） | 分组问题 |
| 核心算法 | 动态规划 / 贪心（累加上升段） | 贪心 + 排序 |
| 正确性重点 | 状态转移的完备性 | 上界论证 / 交换论证 |

两道题都强调：

**先判断"顺序约束是否存在"，它决定了问题是需要状态机，还是可以直接分组。**

**一句话总结**

3727 的核心在于认识到"任意重排"使位置只剩下"⌈n/2⌉ 个加号、⌊n/2⌋ 个减号"的计数信息，问题由排列退化为分组；贪心地让平方值最大的 ⌈n/2⌉ 个取正，排序后以 ⌊n/2⌋ 为分界点切一刀即可，并通过"可达 + 上界"证明其全局最优。
