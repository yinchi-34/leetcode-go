## 2. 题意理解（Problem Understanding）

给定 $`0 \ldots n-1`$ 的一个排列 `nums`。选定一个非负整数 $`k`$ 后，只允许交换满足 `nums[i] & nums[j] == k` 的两个位置。求能把数组排成升序的最大 $`k`$；数组本来有序时返回 0。

**示例**

- 输入：`nums = [0,3,2,1]`
- 输出：`1`（$`3 \mathbin{\&} 1 = 1`$，交换 3 和 1 即有序）

**关键要求**

1. 输入约束：$`1 \le n \le 10^5`$，`nums` 恰好包含 $`0 \ldots n-1`$ 各一次。
2. 交换条件是按位与**恰好等于** $`k`$，不是“包含 $`k`$”。交换次数不限，不动点也可以参与交换。
3. 边界：数组已经有序时答案规定为 0；否则 $`k = 0`$ 一定可行（见 4.4），所以答案总存在。

## 3. 初始思路（Initial Approach）

### 第一次想到：这是一道位运算题

读题时能判断出要用位运算，但从题意（交换条件、能否排好序）到题目要的答案（一个具体的 $`k`$），这一步转换读起来很拗口。

### 遇到的问题

代码写成了“跳过放对位置的数，其余的数依次做 `k &= nums[i]`”，测试也能通过，但对两件事没有把握：

- `k` 只是记录了“当前的值”，为什么一路按位与下去就是答案？这算不算贪心？
- 数字 0 要不要单独考虑？测试用例该按什么分类？

### 思维转变

从：

> 关注交换条件：哪些数能和哪些数交换，0 在不在原位，用例要覆盖哪些“乱序的方式”。

转变为：

> 这道题本质上是求置换的支撑集，再对支撑集做按位与。按位与可以边遍历边做，不需要先把支撑集存下来。

转变之后，0 不再是特殊情况：0 不在原位，就说明它在支撑集里，按同一条规则参与按位与。测试也随之简化：代码只有“支撑集为空”和“支撑集不为空”两条路径，各用一个用例覆盖（见 4.6）。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 支撑集按位与（Bitwise AND over the Support）

本节下标从 0 开始。

### 4.1 输入（Input）

把输入看作置换 $`\pi`$，$`\pi(i) = \mathrm{nums}[i]`$，它是 $`\{0, \ldots, n-1\}`$ 到自身的双射。

- 满足 $`\pi(i) = i`$ 的 $`i`$ 称为不动点。
- 支撑集 $`\mathrm{supp}(\pi) = \{i : \pi(i) \ne i\}`$。
- 数组有序当且仅当 $`\pi = \mathrm{id}`$，即支撑集为空。

### 4.2 输出（Output）

称 $`k`$ **可行**，指存在有限次交换，每次交换的两个值按位与恰为 $`k`$，最终 $`\pi = \mathrm{id}`$。

输出 $`\mathrm{res}`$ 满足：

- 若 $`\mathrm{supp}(\pi) = \varnothing`$，$`\mathrm{res} = 0`$；
- 否则 $`\mathrm{res}`$ 是可行的，且任何可行的 $`k`$ 都满足 $`k \le \mathrm{res}`$。

下面将证明它等于支撑集中所有元素的按位与：

```math
M = \mathop{\&}_{v \in \mathrm{supp}(\pi)} v
```

### 4.3 伪代码（Pseudocode）

```text
MAX-K-TO-SORT(A)
    res ← -1                      ▷ 二进制全 1，是按位与的单位元
    for i ← 0 to n - 1
        if A[i] ≠ i               ▷ i 在支撑集中
            res ← res AND A[i]
    if res == -1                  ▷ 支撑集为空
        return 0
    return res
```

**状态定义**

- `res`：已扫描部分中，支撑集元素的按位与；还没遇到支撑集元素时为 `-1`。
- `i`：当前检查的位置。

### 4.4 正确性（Correctness）

**证明方法：循环不变式 + 上界（必要性）+ 构造（可达性）**

记号：$`x \subseteq y`$ 表示 $`x`$ 的每个为 1 的二进制位在 $`y`$ 中也为 1，即 $`x \mathbin{\&} y = x`$。

#### 一、正确性依赖的关键条件

1. **子掩码性质（位运算事实）**：若 $`a \mathbin{\&} b = k`$，则 $`k \subseteq a`$ 且 $`k \subseteq b`$。若 $`k \subseteq v`$ 对集合中每个 $`v`$ 成立，则 $`k \subseteq \mathop{\&} v`$。$`x \subseteq y`$ 推出 $`x \le y`$。
2. **支撑集在 $`\pi`$ 下封闭（引理 1）**：$`\{\pi(i) : i \in \mathrm{supp}(\pi)\} = \mathrm{supp}(\pi)`$。因此“错位的值”和“错位的位置”是同一个集合，代码中 `A[i]` 的按位与就是 $`M`$。
3. **上界（引理 2）**：支撑集不为空时，任何可行的 $`k`$ 都满足 $`k \subseteq M`$。
4. **可达性（引理 3）**：支撑集不为空时，$`M`$ 可行。

**引理 1。** 不动点的集合 $`F`$ 在 $`\pi`$ 下映到自身。$`\pi`$ 是双射，所以它把 $`F`$ 的补集，也就是支撑集，映到 $`F`$ 的补集。

**引理 2。** 取任意 $`v \in \mathrm{supp}(\pi)`$。值 $`v`$ 当前不在位置 $`v`$，最终必须到达位置 $`v`$，而只有交换能移动元素，所以 $`v`$ 至少参与一次交换。设对方是 $`u`$，则 $`v \mathbin{\&} u = k`$，由条件 1 得 $`k \subseteq v`$。对所有 $`v \in \mathrm{supp}(\pi)`$ 成立，故 $`k \subseteq M`$，从而 $`k \le M`$。

**引理 3（构造）。** 因为 $`M \subseteq \min \mathrm{supp}(\pi) \le n-1`$，值 $`M`$ 在数组中存在。令参与集合 $`T = \mathrm{supp}(\pi) \cup \{M\}`$，并称 $`M`$ 为**枢纽**。

- 若 $`M \in \mathrm{supp}(\pi)`$，则 $`T = \mathrm{supp}(\pi)`$；
- 否则 $`M`$ 是不动点，正位于位置 $`M`$。

由引理 1，$`T`$ 中的值所占的位置集合恰好也是 $`T`$。对任意 $`x \in T`$ 有 $`M \subseteq x`$，所以 $`M \mathbin{\&} x = M`$：**枢纽与 $`T`$ 中任何元素的交换都合法。** 只用这类交换，重复以下步骤：

- **步骤 A**：枢纽位于位置 $`p \ne M`$。由于 $`p \in T`$，值 $`p`$ 在 $`T`$ 中且不是枢纽，交换枢纽与值 $`p`$，值 $`p`$ 归位。
- **步骤 B**：枢纽已在位置 $`M`$，但还有 $`x \in T`$ 不在位置 $`x`$。交换枢纽与 $`x`$；之后枢纽不在位置 $`M`$，下一步是步骤 A。
- 都不满足时，$`T`$ 中所有元素归位，而 $`T`$ 以外的元素都是不动点、从未被移动，所以 $`\pi = \mathrm{id}`$。

终止性：设 $`\Phi`$ 为 $`T`$ 中除枢纽外不在原位的元素个数。步骤 A 使 $`\Phi`$ 减 1，步骤 B 不改变 $`\Phi`$，但其后紧跟一次步骤 A（步骤 B 刚把枢纽放到 $`x`$ 原来的位置 $`q \ne M`$，且步骤 A 不会把已归位的元素移开）。所以每两步 $`\Phi`$ 至少减 1，至多 $`2\lvert T \rvert`$ 次交换后结束。

#### 二、正确性证明

先说明代码算出的就是 $`M`$。

**循环不变式（Loop Invariant）**

在第 $`i`$ 次迭代开始时：

**不变式 I：前缀中支撑集元素的按位与**

`res` 等于 $`\{\pi(j) : 0 \le j < i,\ \pi(j) \ne j\}`$ 中所有值的按位与；该集合为空时，`res` $`= -1`$。

**初始化（Initialization）**

$`i = 0`$ 时集合为空，`res` $`= -1`$，成立。

**保持（Maintenance）**

- 若 $`i`$ 是不动点：集合不变，`res` 不变，仍成立。
- 若 $`i \in \mathrm{supp}(\pi)`$：新集合多了 $`\pi(i)`$。原集合为空时，`res` 由 $`-1 \mathbin{\&} \pi(i) = \pi(i)`$ 得到（`-1` 在补码中全为 1）；否则由按位与的结合律，`res` 更新为原值与 $`\pi(i)`$ 的按位与。两种情况都成立。

**终止（Termination）**

循环在 $`i = n`$ 时结束，由引理 1，此时集合就是 $`\mathrm{supp}(\pi)`$。

- 支撑集为空：`res` $`= -1`$，返回 0，符合题意。
- 支撑集不为空：`res` $`= M`$。所有值都非负，其按位与的符号位为 0，不可能等于 $`-1`$，所以不会误判为支撑集为空，返回 $`M`$。

#### 三、结论

$`\pi = \mathrm{id}`$ 时返回 0。否则返回 $`M`$：由引理 3，$`M`$ 可行；由引理 2，任何可行的 $`k`$ 都不超过 $`M`$。因此 $`M`$ 就是最大可行值，算法对所有合法输入正确。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为数组长度。

**时间复杂度：$`\Theta(n)`$**

循环恰好执行 $`n`$ 次，每次一次比较和至多一次按位与，均为常数时间。

**空间复杂度：$`O(1)`$**

只用 `res`、`i`、`n` 三个变量，不修改输入，也不把支撑集存下来。引理 3 的交换过程只用于证明，代码不执行它。

### 4.6 测试设计（Test Design）

测试按算法的机制设计。代码只有两条路径：支撑集为空时不做任何按位与，直接返回 0；支撑集不为空时，对支撑集元素逐个按位与。0 不需要单独考虑：它在支撑集中时，按同一条规则参与按位与。所以每条路径各用一个用例。

| 用例 | 输入 | 预期 | 覆盖的路径 |
|---|---|---|---|
| `identity_permutation` | `[0,1,2,3]` | 0 | $`\pi = \mathrm{id}`$，支撑集为空 |
| `nonempty_support` | `[0,1,2,3,4,6,7,5]` | 4 | 支撑集 $`\{5, 6, 7\}`$，$`6 \mathbin{\&} 7 \mathbin{\&} 5 = 4`$ |

第二个用例这样选，是为了让常见的写错方式都会得到不同的结果：

| 假设代码写错 | 会得到 |
|---|---|
| 初值写成 `k := 0` | 0 |
| 不动点也参与按位与 | 0 |
| 只算支撑集的前两个元素 | $`6 \mathbin{\&} 7 = 6`$ |

此外，答案 4 是一个不动点，不在支撑集中，这说明枢纽可以是不动点（引理 3）。

**补充检验**：在仓库之外对 $`n \le 7`$ 的全部排列做了穷举对拍（对每个 $`k`$ 搜索交换能到达的所有状态），结果与 $`M`$ 全部一致。

## 5. 思维难点（Learning Notes）

### 难点一：一路按位与下去，算不算贪心？

`k` 只记录了“当前的值”，每遇到一个支撑集元素就收紧一次，看起来像贪心。

**理解过程**

按二进制位分开看。答案的某一位能保留 1，当且仅当支撑集中每个元素这一位都是 1；只要有一个元素这一位是 0，这一位就必须清零。各位之间互不影响，保留这一位不会妨碍另一位，所以把所有能保留的 1 全部留下，就得到最大的候选值。`k &= nums[i]` 一次完成了所有位的这种判断。

这里没有“从多个方案中选一个局部最优”的过程，每个支撑集元素只是提供一个必须满足的限制，按位与把这些限制逐个合并。所以更准确的说法是“按位与累积”，而不是贪心。另外，按位与只给出了上界，还要用引理 3 证明这个上界真的能达到。

**可迁移思维：** 当目标值的每一位可以独立决定、各位之间没有取舍时，“每一位尽量取 1”就是最优，不需要贪心的交换论证。判断是不是贪心，看的是有没有“在多个方案中做选择”。

### 难点二：不动点为什么不限制答案，却可能被借来用？

**理解过程**

上界只来自“支撑集元素必须移动”。不动点可以一直不动，所以它不提出任何限制。

但证明可达时，不动点可能派上用场。例如 `[0,1,2,5,4,6,3,7]`，支撑集是 $`\{3, 5, 6\}`$，两两按位与分别是 $`5 \mathbin{\&} 6 = 4`$、$`5 \mathbin{\&} 3 = 1`$、$`6 \mathbin{\&} 3 = 2`$，没有一对等于 $`M = 0`$，支撑集元素之间一次都换不了。可行的做法是借用不动点 0：0 与任何数的按位与都是 0，先把 0 换出去当“空位”，带着支撑集元素逐个归位，最后 0 回到原处。

**可迁移思维：** 证明“最大值可达”时，不要把可用资源限制在问题看似涉及的那部分。中间状态可以暂时破坏已经正确的部分，只要最终恢复。

### 难点三：测试用例按什么设计？

一开始按“乱序的方式”列了很多用例：0 是否错位、公共位在低位还是高位、错位的数有几个，等等。后来又按 0 的位置和支撑集大小做等价类划分。

**理解过程**

把题目理解成“求支撑集再做按位与”之后，这些区别都只是同一条规则的不同输入，不是代码中不同的处理。代码真正不同的路径只有两条，所以两个用例就够了。关键在于第二个用例要选得好，让常见的写错方式都暴露出来（见 4.6）。

**可迁移思维：** 测试应该跟着自己对机制的理解走，而不是看到表面不同就各加一个用例。先说清代码有哪几条路径，每条路径选一个能暴露常见错误的输入；需要兜底时，用暴力解法做对拍。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Submask（子掩码）**：在本题中，$`a \mathbin{\&} b = k`$ 意味着 $`k`$ 是 $`a`$ 和 $`b`$ 的公共子掩码，于是“支撑集中每个元素都要参与交换”直接变成“$`k`$ 是支撑集元素的公共子掩码”，而一组数的最大公共子掩码就是它们的按位与。适用于约束形如“按位与等于 / 包含某值”的问题。限制：子掩码关系推出数值不超过，反过来不成立，比较“最大”时要先在子掩码意义下得到上界。
2. **Upper Bound plus Construction（上界与构造）**：在本题中，引理 2 证明任何可行 $`k`$ 都不超过 $`M`$，引理 3 构造交换序列证明 $`M`$ 可达，两者合起来才说明 $`M`$ 是最大值。适用于“求最大 / 最小的可行参数”一类问题。限制：只证上界会漏掉“上界达不到”的情况，只给构造不能说明更大的值不可行，二者缺一不可。
3. **Star Transposition（星形对换）**：在本题中，所有交换都经过枢纽 $`M`$，按“枢纽在哪个位置，就把属于那个位置的元素换回来”的规则，在至多 $`2\lvert T \rvert`$ 次交换内排好 $`T`$。适用于“只有某个特殊元素能和其他元素交换”的排序问题，例如借助空位移动元素。前提是枢纽与集合中每个元素的交换都合法，而且集合占据的位置恰好就是这些元素的目标位置（本题由引理 1 保证）。
4. **Fold with Identity Element（以单位元为初值的折叠）**：在本题中，`res` 以 `-1` 开始逐个按位与，同时用 `-1` 判断支撑集是否为空。适用于各种对集合做结合运算的扫描。用单位元兼作“空集”哨兵时，要保证合法数据不会产生它；本题所有值非负，按位与不可能是 `-1`。
5. **Loop Invariant（循环不变式）**：在本题中，“`res` 是前缀中支撑集元素的按位与”把代码与数学定义 $`M`$ 对应起来，让 4.4 的其余证明只需讨论 $`M`$ 本身。适用于一切累积型扫描。

- [1202. 交换字符串中的元素](https://leetcode.cn/problems/smallest-string-with-swaps/) — 同样是“交换受限能到达哪些排列”：可交换关系构成图，同一连通分量内任意排列都可达，与本题“枢纽能和 $`T`$ 中每个元素交换，所以 $`T`$ 可任意重排”是同一个可达性论证。
- [2948. 交换得到字典序最小的数组](https://leetcode.cn/problems/make-lexicographically-smallest-array-by-swapping-elements/) — 交换条件依赖元素的值（差不超过 `limit`），要先分析值之间的可交换关系再决定每组元素能去哪里，与本题按值的位关系分析交换的建模方式相同。
- [Codeforces 1828B. Permutation Swap](https://codeforces.com/problemset/problem/1828/B) — 同样求“允许交换的最大参数”使排列可排序：只能交换距离为 $`k`$ 倍数的位置，答案是所有 $`\lvert p_i - i \rvert`$ 的最大公约数，同样由“支撑集元素必须移动”给出上界、再构造证明可达。

---

**一句话总结**

这道题本质上是求置换的支撑集再做按位与：支撑集元素都必须参与交换，所以 $`k`$ 不超过它们的按位与 $`M`$；$`M`$ 又能和每个支撑集元素合法交换，可以当枢纽把数组排好，所以答案就是 $`M`$。
