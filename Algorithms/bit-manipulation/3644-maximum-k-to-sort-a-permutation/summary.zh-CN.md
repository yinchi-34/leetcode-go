## 2. 题意理解（Problem Understanding）

给定 $`0 \ldots n-1`$ 的一个排列 `nums`。选定一个非负整数 $`k`$ 后，只允许交换满足 `nums[i] & nums[j] == k` 的两个位置。求能把数组排成升序的最大 $`k`$；数组本来有序时返回 0。

**示例**

- 输入：`nums = [0,3,2,1]`
- 输出：`1`（$`3 \mathbin{\&} 1 = 1`$，交换 3 和 1 即有序）

**关键要求**

1. 输入约束：$`1 \le n \le 10^5`$，`nums` 恰好包含 $`0 \ldots n-1`$ 各一次。
2. 交换条件是按位与**恰好等于** $`k`$，不是“包含 $`k`$”。交换次数不限，也可以交换已经就位的元素。
3. 边界：数组已经有序时答案规定为 0；只要有错位，$`k = 0`$ 一定可行（见 4.4），所以答案总存在。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 错位元素按位与（Bitwise AND of Misplaced Elements）

本节下标从 0 开始。

### 4.1 输入（Input）

排列 $`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$，满足 $`\{a_0, \ldots, a_{n-1}\} = \{0, \ldots, n-1\}`$。

### 4.2 输出（Output）

称 $`k`$ **可行**，指存在有限次交换，每次交换的两个值按位与恰为 $`k`$，最终 $`a_i = i`$ 对所有 $`i`$ 成立。

设错位值集合 $`S = \{a_i : a_i \ne i\}`$。输出 $`\mathrm{res}`$ 满足：

- 若 $`S = \varnothing`$，$`\mathrm{res} = 0`$；
- 否则 $`\mathrm{res}`$ 是可行的，且任何可行的 $`k`$ 都满足 $`k \le \mathrm{res}`$。

下面将证明它等于

```math
M = \mathop{\&}_{v \in S} v
```

### 4.3 伪代码（Pseudocode）

```text
MAX-K-TO-SORT(A)
    res ← -1                      ▷ 二进制全 1，是按位与的单位元
    for i ← 0 to n - 1
        if A[i] ≠ i
            res ← res AND A[i]
    if res == -1                  ▷ 没有错位元素，数组已有序
        return 0
    return res
```

**状态定义**

- `res`：已扫描部分中所有错位值的按位与；还没遇到错位值时为 `-1`。
- `i`：当前检查的位置。

### 4.4 正确性（Correctness）

**证明方法：循环不变式 + 上界（必要性）+ 构造（可达性）**

记号：$`x \subseteq y`$ 表示 $`x`$ 的每个为 1 的二进制位在 $`y`$ 中也为 1，即 $`x \mathbin{\&} y = x`$。

#### 一、正确性依赖的关键条件

1. **子掩码性质（位运算事实）**：若 $`a \mathbin{\&} b = k`$，则 $`k \subseteq a`$ 且 $`k \subseteq b`$。若 $`k \subseteq v`$ 对集合中每个 $`v`$ 成立，则 $`k \subseteq \mathop{\&} v`$。$`x \subseteq y`$ 推出 $`x \le y`$。
2. **错位值与错位位置是同一集合（引理 1）**：$`S = \{i : a_i \ne i\}`$。
3. **上界（引理 2）**：$`S \ne \varnothing`$ 时，任何可行的 $`k`$ 都满足 $`k \subseteq M`$。
4. **可达性（引理 3）**：$`S \ne \varnothing`$ 时，$`M`$ 可行。

**引理 1。** 已就位的值集合 $`F = \{a_i : a_i = i\}`$ 与已就位位置集合 $`\{i : a_i = i\}`$ 显然相同。$`S`$ 是全体值去掉 $`F`$，错位位置集合是全体位置去掉 $`F`$，而全体值与全体位置都是 $`\{0, \ldots, n-1\}`$，所以两者相等。

**引理 2。** 取任意 $`v \in S`$。$`v`$ 当前不在位置 $`v`$，最终必须到达位置 $`v`$，而只有交换能移动元素，所以 $`v`$ 至少参与一次交换，设对方是 $`u`$，则 $`v \mathbin{\&} u = k`$，由条件 1 得 $`k \subseteq v`$。对所有 $`v \in S`$ 成立，故 $`k \subseteq M`$，从而 $`k \le M`$。

**引理 3（构造）。** 因为 $`M \subseteq \min S \le n-1`$，值 $`M`$ 在数组中存在。令参与集合 $`T = S \cup \{M\}`$，并称 $`M`$ 为**枢纽**。

- 若 $`M \in S`$，则 $`T = S`$；
- 若 $`M \notin S`$，则 $`M`$ 是已就位元素，正位于位置 $`M`$。

由引理 1，$`T`$ 中值所占的位置集合恰好也是 $`T`$。对任意 $`x \in T`$ 有 $`M \subseteq x`$，所以 $`M \mathbin{\&} x = M`$：**枢纽与 $`T`$ 中任何元素的交换都合法。** 只用这类交换，重复以下步骤：

- **步骤 A**：枢纽位于位置 $`p \ne M`$。由于 $`p \in T`$，值 $`p`$ 在 $`T`$ 中且不是枢纽，交换枢纽与值 $`p`$，值 $`p`$ 归位。
- **步骤 B**：枢纽已在位置 $`M`$，但还有 $`x \in T`$ 不在位置 $`x`$。交换枢纽与 $`x`$；之后枢纽不在家，下一步是步骤 A。
- 都不满足时，$`T`$ 中所有元素就位，而 $`T`$ 以外的元素从未被移动、本来就位，数组有序。

终止性：设 $`\Phi`$ 为 $`T`$ 中除枢纽外不在家的元素个数。步骤 A 使 $`\Phi`$ 减 1，步骤 B 不改变 $`\Phi`$，但其后紧跟一次步骤 A（步骤 B 刚把枢纽放到 $`x`$ 原来的位置 $`q \ne M`$，且步骤 A 不会把已归位的元素移开）。所以每两步 $`\Phi`$ 至少减 1，至多 $`2\lvert T \rvert`$ 次交换后结束。

#### 二、正确性证明

先说明代码算出的就是 $`M`$。

**循环不变式（Loop Invariant）**

在第 $`i`$ 次迭代开始时：

**不变式 I：前缀错位值的按位与**

`res` 等于 $`\{a_j : 0 \le j < i,\ a_j \ne j\}`$ 中所有值的按位与；该集合为空时，`res` $`= -1`$。

**初始化（Initialization）**

$`i = 0`$ 时集合为空，`res` $`= -1`$，成立。

**保持（Maintenance）**

- 若 $`a_i = i`$：集合不变，`res` 不变，仍成立。
- 若 $`a_i \ne i`$：新集合多了 $`a_i`$。原集合为空时，`res` 由 $`-1 \mathbin{\&} a_i = a_i`$ 得到（`-1` 在补码中全为 1）；否则由按位与的结合律，`res` 更新为原值与 $`a_i`$ 的按位与。两种情况都成立。

**终止（Termination）**

循环在 $`i = n`$ 时结束，此时集合就是 $`S`$。

- $`S = \varnothing`$：`res` $`= -1`$，返回 0，符合题意。
- $`S \ne \varnothing`$：`res` $`= M`$。所有 $`a_i \ge 0`$，其按位与的符号位为 0，不可能等于 $`-1`$，所以不会误判为“已有序”，返回 $`M`$。

#### 三、结论

数组有序时返回 0。否则返回 $`M`$：由引理 3，$`M`$ 可行；由引理 2，任何可行的 $`k`$ 都不超过 $`M`$。因此 $`M`$ 就是最大可行值，算法对所有合法输入正确。

另外，在仓库之外用 Python 对 $`n \le 7`$ 的全部排列做了穷举搜索（对每个 $`k`$ 搜索交换状态图），结果与 $`M`$ 全部一致。这只是辅助检验，不替代上面的证明。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为数组长度。

**时间复杂度：$`\Theta(n)`$**

循环恰好执行 $`n`$ 次，每次一次比较和至多一次按位与，均为常数时间。

**空间复杂度：$`O(1)`$**

只用 `res`、`i`、`n` 三个变量，不修改输入，不分配额外数组。引理 3 的交换过程只用于证明，代码不执行它。

### 4.6 测试设计（Test Design）

测试对象是 `sortPermutation(nums)` 的返回值，用 Go 的表驱动测试（table-driven tests）组织。每个用例都能用一句话说清：预期结果是 ___，检查的是 ___。

**设计步骤**

1. **边界值分析（Boundary Value Analysis）**：最小输入 `[0]`。
2. **等价类划分（Equivalence Partitioning）**：先按答案是否为 0 分组，再按答案的成因细分。
3. **组合测试（Combinatorial Testing）**：多个错位数字一起作用。
4. **错误推测（Error Guessing）**：假设代码写错，看哪个用例能发现。

**答案为 0**

| 类别 | 用例 | 输入 | 检查什么 |
|---|---|---|---|
| A. 没有错位 | `single_element`、`already_sorted` | `[0]`、`[0,1,2,3]` | 已经有序时返回 0 |
| B. 0 错位 | `misplaced_zero` | `[3,2,1,0]` | 0 要移动，答案只能是 0 |
| C1. 有一对没有公共位 | `no_common_bits` | `[0,2,3,1]` | 0 已归位，答案也可能是 0 |
| C2. 两两有公共位，合起来没有 | `pairwise_common_bits_all_zero` | `[0,1,2,5,4,6,3,7]` | 要把所有错位数字合起来算，不能只看两个 |

**为什么答案为 0 恰好分成这四类**

沿用 4.2 的记号：$`S`$ 是错位数字的集合，$`M`$ 是它们的按位与。下面说明 A、B、C1、C2 不重不漏。

1. **A 与其余三类**：$`S`$ 为空就是 A，题意规定答案为 0。$`S`$ 不为空时，由 4.4，答案等于 $`M`$，所以“答案为 0”就是 $`M = 0`$。
2. **B 与 C**：$`M = 0`$ 时，按 0 是否在 $`S`$ 中再分。0 在 $`S`$ 中就是 B；这时不用看别的数字，因为 0 与任何数按位与都是 0，$`M`$ 一定是 0。0 不在 $`S`$ 中就是 C，这时 $`S`$ 里都是正数，答案为 0 只能来自多个数字合起来没有公共位。
3. **C1 与 C2**：在 C 中，看是否存在一对错位数字按位与为 0。存在就是 C1，不存在就是 C2。

每一步都是“是 / 否”二选一，所以任何答案为 0 的输入恰好落在一类中。

**C2 至少要有 3 个错位数字。** 排列中错位数字不会只有 1 个：若数字 $`v`$ 放在位置 $`i 
e v`$，由引理 1，数字 $`i`$ 也错位。若恰好有 2 个，$`M`$ 就是这一对的按位与，$`M = 0`$ 说明这一对没有公共位，属于 C1。所以 C2 至少要 3 个错位数字，`[0,1,2,5,4,6,3,7]` 的 5、6、3 就是这样的例子。在 C2 中，任意两个错位数字的按位与都不是 0，它们之间不能直接交换，只能借已归位的 0 中转，这正是引理 3 的枢纽在已归位元素上的情况。

**答案不为 0**

| 类别 | 用例 | 输入 | 检查什么 |
|---|---|---|---|
| D. 只有一位公共的 1 | `common_low_bit`、`common_high_bit` | `[0,3,2,1]`、`[0,1,3,2]` | 已归位的 0 不参与计算 |
| E. 有多位公共的 1 | `multiple_common_bits` | `[0,1,2,7,4,5,6,3]` | 答案可以有多个 1 |
| F. 后面的数字还会改变结果 | `multiple_misplaced` | `[0,1,2,7,4,3,6,5]` | 要算完全部错位数字 |
| G. 答案是已归位的数字 | `answer_in_place` | `[0,1,2,3,4,6,5,7]` | 答案不一定是错位数字 |

**错误推测对照**

| 假设的错误 | 能发现它的用例 |
|---|---|

## 5. 思维难点（Learning Notes）

### 难点一：枢纽 $`M`$ 可能本来就在正确位置上

直觉上会以为“已经就位的元素与答案无关”，于是只在错位元素之间找交换。但错位元素两两之间可能没有一对的按位与恰好等于 $`M`$。

**理解过程**

看测试 `pairwise_common_bits_all_zero`：`[0,1,2,5,4,6,3,7]` 中错位值是 $`\{5, 6, 3\}`$，两两按位与分别是 $`5 \mathbin{\&} 6 = 4`$、$`5 \mathbin{\&} 3 = 1`$、$`6 \mathbin{\&} 3 = 2`$，没有一对等于 $`M = 0`$。可行的做法是借用已就位的 0：0 与任何数的按位与都是 0，先把 0 换出去当“空位”，带着错位元素逐个归位，最后 0 回到原处。

这同时解释了为什么就位元素**不影响答案**：上界只来自“错位元素必须移动”，就位元素可以不动，所以不贡献约束；而充分性允许它们临时离开再回来。

**可迁移思维：** 证明“最大值可达”时，不要把可用资源限制在问题看似涉及的那部分。中间状态可以暂时破坏已经正确的部分，只要最终恢复。

### 难点二：为什么用 `-1` 作初值，又为什么能用它判断“已有序”

**理解过程**

按位与的单位元是二进制全 1：对任意 $`x`$，全 1 与 $`x`$ 的按位与仍是 $`x`$。Go 的 `int` 是有符号补码，`-1` 正好全为 1，所以 `res := -1` 等价于“空集合的按位与”。

判断已有序则依赖值域：题目中所有值都非负，非负数的按位与符号位为 0，不可能等于 `-1`。因此 `res == -1` 当且仅当一次按位与都没做，即没有错位元素。如果值可能为负，这个哨兵就不再可靠，需要改用单独的布尔标记。

**可迁移思维：** 对一组数做折叠（求和、求积、按位与、按位或、取最小值）时，初值取该运算的单位元。用单位元兼作“空集”哨兵前，要确认它不会被合法数据算出来。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Submask（子掩码）**：在本题中，$`a \mathbin{\&} b = k`$ 意味着 $`k`$ 是 $`a`$ 和 $`b`$ 的公共子掩码，于是“每个错位元素都要参与交换”直接变成“$`k`$ 是所有错位元素的公共子掩码”，而一组数的最大公共子掩码就是它们的按位与。适用于约束形如“按位与等于 / 包含某值”的问题。限制：子掩码关系推出数值不超过，反过来不成立，比较“最大”时要先在子掩码意义下得到上界。
2. **Upper Bound plus Construction（上界与构造）**：在本题中，引理 2 证明任何可行 $`k`$ 都不超过 $`M`$，引理 3 构造交换序列证明 $`M`$ 可达，两者合起来才说明 $`M`$ 是最大值。适用于“求最大 / 最小的可行参数”一类问题。限制：只证上界会漏掉“上界达不到”的情况，只给构造不能说明更大的值不可行，二者缺一不可。
3. **Star Transposition（星形对换）**：在本题中，所有交换都经过枢纽 $`M`$，按“枢纽在哪个位置，就把属于那个位置的元素换回来”的规则，在至多 $`2\lvert T \rvert`$ 次交换内排好 $`T`$。适用于“只有某个特殊元素能和其他元素交换”的排序问题，例如用空位移动元素。前提是枢纽与集合中每个元素的交换都合法，而且集合占据的位置恰好就是这些元素的目标位置（本题由引理 1 保证）。
4. **Fold with Identity Element（以单位元为初值的折叠）**：在本题中，`res` 以 `-1` 开始逐个按位与。适用于各种对集合做结合运算的扫描。用单位元兼作“空集”哨兵时，要保证合法数据不会产生它。
5. **Loop Invariant（循环不变式）**：在本题中，“`res` 是前缀错位值的按位与”把代码与数学定义 $`M`$ 对应起来，让第 4.4 节的正确性证明只需讨论 $`M`$ 本身。适用于一切累积型扫描。

## 8. 关联题目（Related Problems）

- [1202. 交换字符串中的元素](https://leetcode.cn/problems/smallest-string-with-swaps/) — 同样是“交换受限能到达哪些排列”：可交换关系构成图，同一连通分量内任意排列都可达，与本题“枢纽能和 $`T`$ 中每个元素交换，所以 $`T`$ 可任意重排”是同一个可达性论证。
- [2948. 交换得到字典序最小的数组](https://leetcode.cn/problems/make-lexicographically-smallest-array-by-swapping-elements/) — 交换条件依赖元素的值（差不超过 `limit`），要先分析值之间的可交换关系再决定每组元素能去哪里，与本题按值的位关系分析交换的建模方式相同。
- [Codeforces 1828B. Permutation Swap](https://codeforces.com/problemset/problem/1828/B) — 同样求“允许交换的最大参数”使排列可排序：只能交换距离为 $`k`$ 倍数的位置，答案是所有 $`\lvert p_i - i \rvert`$ 的最大公约数，同样由“错位元素必须移动”给出上界、再构造证明可达。

---

**一句话总结**

每个错位元素都必须参与交换，所以 $`k`$ 是它们的公共子掩码，最大不超过它们的按位与 $`M`$；而 $`M`$ 能和每个错位元素合法交换，可以当枢纽把数组排好，所以答案就是错位元素的按位与。
