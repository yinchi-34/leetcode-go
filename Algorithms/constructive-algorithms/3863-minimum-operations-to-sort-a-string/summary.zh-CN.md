## 2. 题意理解（Problem Understanding）

给定只含小写字母的字符串 `s`。每次操作选一个**不等于整个字符串**的连续子串，把它按非降序排好。求让整个 `s` 变成非降序的最少操作次数；做不到时返回 `-1`。

**示例**

- 输入：`s = "dog"`，输出：`1`。排序 `"og"` 得到 `"dgo"`。
- 输入：`s = "card"`，输出：`2`。先排 `"car"` 得到 `"acrd"`，再排 `"rd"` 得到 `"acdr"`。
- 输入：`s = "gf"`，输出：`-1`。真子串只有单个字符，排序不改变任何东西。

**关键要求**

1. $`1 \leq n \leq 10^5`$，`s` 只含小写英文字母。
2. 每次操作的区间 $`[l, r]`$ 必须满足 $`[l, r] \neq [0, n-1]`$，但长度可以是 $`n-1`$。
3. 已经有序时答案为 `0`；长度为 2 且无序时无解。

## 3. 算法表达（Algorithm Specification）

**算法名称：** 极值位置分类讨论（Case Analysis on Extreme Positions）

### 3.1 输入（Input）

字符串 $`s = \langle s_0, s_1, \ldots, s_{n-1} \rangle`$，满足：

- $`1 \leq n \leq 10^5`$；
- 每个 $`s_i`$ 是小写字母，按字母序比较。

记 $`m = \min_i s_i`$，$`M = \max_i s_i`$。

### 3.2 输出（Output）

记 $`f(s)`$ 为把 `s` 排成非降序所需的最少操作次数，不可能时 $`f(s) = -1`$。算法返回 $`f(s)`$。

设 `s` 无序且 $`n \geq 3`$，定义四个布尔量：

| 记号 | 含义 |
|---|---|
| $`L`$ | $`s_0 = m`$，左端已是全局最小值 |
| $`R`$ | $`s_{n-1} = M`$，右端已是全局最大值 |
| $`I_m`$ | 存在 $`1 \leq i \leq n-2`$ 使 $`s_i = m`$，最小值出现在内部 |
| $`I_M`$ | 存在 $`1 \leq j \leq n-2`$ 使 $`s_j = M`$，最大值出现在内部 |

本题解要证明：

```math
f(s) =
\begin{cases}
0, & s \text{ 已有序} \\
-1, & s \text{ 无序且 } n = 2 \\
1, & s \text{ 无序}, n \geq 3, L \lor R \\
2, & s \text{ 无序}, n \geq 3, \lnot L \land \lnot R, I_m \lor I_M \\
3, & \text{其余情况}
\end{cases}
```

### 3.3 伪代码（Pseudocode）

下标从 0 开始。

```text
MIN-OPERATIONS(s)
    n ← length(s)
    m ← 'z', M ← 'a'
    sorted ← true
    for i ← 0 to n - 1
        M ← max(M, s[i])
        m ← min(m, s[i])
        if i > 0 and s[i-1] > s[i]
            sorted ← false

    if sorted
        return 0
    if n = 2
        return -1
    if s[0] = m or s[n-1] = M
        return 1
    for i ← 1 to n - 2
        if s[i] = m or s[i] = M
            return 2
    return 3
```

**状态定义**

- `sorted`：`s` 是否已经非降序。
- `m`、`M`：全局最小字符和最大字符，分别从 `'z'`、`'a'` 开始，扫描中不断更新。

内部扫描只看下标 $`1`$ 到 $`n-2`$。走到这一步时已知 $`\lnot L \land \lnot R`$，即 $`s_0 \neq m`$、$`s_{n-1} \neq M`$，所以「最小值出现在最后一位之外」与 $`I_m`$ 等价，「最大值出现在第一位之外」与 $`I_M`$ 等价，一次内部扫描就够了。

### 3.4 正确性（Correctness）

**证明方法：** 对每一类分别给出上界构造（能做到）和下界证明（不能更少）。

#### 一、正确性依赖的关键条件

1. **端点不变性**：任何合法操作都至少保留一个端点不变。
2. **目标串的端点**：排好序的字符串首字符是 $`m`$，末字符是 $`M`$。
3. **长度为 $`n-1`$ 的排序能力**：一次可以排序前 $`n-1`$ 位或后 $`n-1`$ 位，中间元素的排列不需要单独处理。

#### 二、正确性证明

**引理 0（端点不变性）**

设一次操作排序区间 $`[l, r]`$。由于 $`[l, r] \neq [0, n-1]`$，有 $`l \geq 1`$ 或 $`r \leq n-2`$。前者 $`s_0`$ 不变，后者 $`s_{n-1}`$ 不变。

**引理 1（一次完成的充要条件）**

对无序的 `s`，$`f(s) = 1`$ 当且仅当 $`L \lor R`$。

*必要性*：若一次操作后有序，由引理 0，某个端点没动。有序串满足首字符为 $`m`$、末字符为 $`M`$，而操作不改变字符的多重集合，所以没动的那个端点原本就满足 $`s_0 = m`$ 或 $`s_{n-1} = M`$。

*充分性*：若 $`L`$ 成立，排序 $`[1, n-1]`$。结果首字符为 $`m`$，不大于任何字符，其余部分已排序，整体有序。$`R`$ 的情形对称，排序 $`[0, n-2]`$。

**引理 2（长度为 2）**

$`n = 2`$ 时真子串只有单个字符，排序不改变字符串。无序的 `s` 永远无法变得有序，$`f(s) = -1`$。

$`n = 1`$ 时字符串必然有序，由 `sorted` 分支返回 0。

**引理 3（恰好两次）**

设 `s` 无序，$`n \geq 3`$，$`\lnot L \land \lnot R`$，且 $`I_m \lor I_M`$，则 $`f(s) = 2`$。

*下界*：由引理 1，$`\lnot L \land \lnot R`$ 时一次不够。

*上界*：若 $`I_m`$ 成立，最小值出现在某个 $`1 \leq i \leq n-2`$，排序 $`[0, n-2]`$ 后首字符变成 $`m`$，此时 $`L`$ 成立，由引理 1 再用一次即可。若 $`I_M`$ 成立，对称地先排序 $`[1, n-1]`$，使末字符变成 $`M`$，再用一次。

**引理 4（恰好三次）**

设 `s` 无序，$`n \geq 3`$，$`\lnot L`$、$`\lnot R`$、$`\lnot I_m`$、$`\lnot I_M`$ 全部成立。

由于 $`m`$ 必须出现，$`\lnot L`$ 说明它不在下标 0，$`\lnot I_m`$ 说明它不在内部，所以它**只**出现在 $`n-1`$；同理 $`M`$ **只**出现在 $`0`$。无序意味着 $`m < M`$。

*下界*：证明任意一次操作后，仍有 $`\lnot L \land \lnot R`$。设操作区间为 $`[l, r]`$：

- 若 $`l \geq 1`$：$`s_0 = M \neq m`$ 不变，所以 $`\lnot L`$。若 $`r \leq n-2`$，$`s_{n-1} = m \neq M`$ 不变；若 $`r = n-1`$，新的末字符是 $`\max(s_l, \ldots, s_{n-1})`$，因为 $`M`$ 只在下标 0，它严格小于 $`M`$。两种情况都有 $`\lnot R`$。
- 若 $`l = 0`$：则 $`r \leq n-2`$，$`s_{n-1} = m \neq M`$ 不变，所以 $`\lnot R`$。新的首字符是 $`\min(s_0, \ldots, s_r)`$，因为 $`m`$ 只在下标 $`n-1`$，它严格大于 $`m`$，所以 $`\lnot L`$。

一次操作后串仍无序（首字符不是 $`m`$），且 $`\lnot L \land \lnot R`$，由引理 1，第二次操作不能完成排序。所以 $`f(s) \geq 3`$。

*上界*：依次排序前 $`n-1`$ 位、后 $`n-1`$ 位、前 $`n-1`$ 位。

1. 排序 $`[0, n-2]`$：$`M`$ 在这一段里，且是这一段的唯一最大值，所以移到下标 $`n-2`$。
2. 排序 $`[1, n-1]`$：因为 $`n \geq 3`$，下标 $`n-2 \geq 1`$ 在这一段里，$`M`$ 移到下标 $`n-1`$，$`R`$ 成立。
3. 由引理 1 的充分性，排序 $`[0, n-2]`$ 后整体有序。

所以 $`f(s) = 3`$。

例如 `"edcba"`：

| 操作 | 排序区间 | 结果 |
|---|---|---|
| 初始 | — | `edcba` |
| 第 1 次 | `[0, 3]` | `bcdea` |
| 第 2 次 | `[1, 4]` | `bacde` |
| 第 3 次 | `[0, 3]` | `abcde` |

#### 三、结论

五种情况互斥且覆盖所有输入：先按是否有序、$`n = 2`$ 分出前两类；剩下的无序且 $`n \geq 3`$ 的串按 $`L \lor R`$、$`I_m \lor I_M`$ 依次分类。每一类都由引理 1 至引理 4 给出了相等的上界和下界，伪代码的分支顺序与这一分类一致，因此算法对所有合法输入返回 $`f(s)`$。

另外，整理本题解时用广度优先搜索枚举了所有由 `a` 到 `d` 组成、长度不超过 6 的字符串，最少操作次数与上述公式全部一致。这只是辅助检查，证明以引理为准。

### 3.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为字符串长度。

**时间复杂度：$`O(n)`$**

第一次扫描求 `sorted`、`m`、`M`，各 $`O(n)`$；判断 $`I_m \lor I_M`$ 的扫描最坏 $`O(n)`$。总计 $`O(n)`$。

**空间复杂度：$`O(1)`$**

只用到常数个变量，不复制字符串。

## 4. 思维难点（Learning Notes）

### 难点一：长度大于 3 时为什么还是最多 3 次？

看 `"cba"` 需要 3 次时，自然会问：字符串更长时，次数会不会随长度增加？

**理解过程**

一次操作可以覆盖 $`n-1`$ 个字符，覆盖范围与 $`n`$ 一起增长。三次构造（前缀、后缀、前缀）只依赖「$`M`$ 能被送到右端」，与中间字符的排列和 $`n`$ 的大小都无关，所以上界始终是 3。下界只看两个端点，也与 $`n`$ 无关。

**可迁移思维：** 当一次操作的覆盖范围随问题规模一起增长时，答案可能是一个与规模无关的常数，应先找常数上界。

## 5. 可迁移知识（Key Takeaways）

1. **Endpoint Invariance（端点不变性）**：在本题中，「不能选整个字符串」推出每次至少一个端点不变，从而得到一次完成的必要条件。适用于操作区间受限的排序、翻转、修改类问题；前提是限制确实阻止区间同时覆盖两端。
   - 例题：[2337. 移动片段得到字符串](https://leetcode.cn/problems/move-pieces-to-obtain-a-string/)。`L` 只能左移、`R` 只能右移、片段不能互相穿过，所以去掉 `_` 后的片段顺序不变，每个 `L` 的目标下标不大于原下标，每个 `R` 不小于原下标。和本题一样，先从操作限制推出不变量，再用不变量判断可行性。
2. **Upper and Lower Bound（上下界夹逼）**：最少次数问题需要两项证明：构造说明「能做到」，不变量说明「做不到更少」。本题中，三次构造给上界，引理 4 证明两次不够。适用于所有求最少操作次数的题目。
   - 例题：[1529. 灯泡开关 IV](https://leetcode.cn/problems/minimum-suffix-flips/)。每次翻转一个后缀，只改变一处相邻位置是否相同，所以答案至少是目标串（前面补一个 `0`）中相邻字符不同的位置数；从左往右遇到不同就翻转，恰好用这么多次，上下界相等。
3. **Value-Preserving Abstraction（最优值保持的抽象）**：把完整的排列压缩成少量特征，并证明最优值只依赖这些特征。适合答案只取少数几个值的构造题；限制是它不保证压缩后还能正确表达状态转移。
   - 例题：[1033. 移动石子直到连续](https://leetcode.cn/problems/moving-stones-until-consecutive/)。三颗石子排序后，最少移动次数只取 0、1、2，只取决于两个间距：两个间距都为 1 时是 0，某个间距不超过 2 时是 1，否则是 2。具体坐标被压缩成「间距是否为 1、是否不超过 2」这几个特征。

这些方法适合「操作能力很强、答案是小常数」的构造与操作次数类问题。遇到这类题目，先研究什么必须保持不变、什么能够改变，而不是直接模拟操作。
