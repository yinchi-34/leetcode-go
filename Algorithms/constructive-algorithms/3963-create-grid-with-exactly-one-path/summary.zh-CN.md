## 2. 题意理解（Problem Understanding）

给定两个整数 $`m`$ 和 $`n`$，构造一个 $`m \times n`$ 的网格，每个格子是 `'.'`（空地）或 `'#'`（障碍）。要求：从左上角 $`(0, 0)`$ 出发，每步只能向右或向下，只经过空地，到达右下角 $`(m-1, n-1)`$ 的路径**恰好有一条**。答案不唯一，返回任意一个合法网格即可。

**示例**

- 输入：`m = 2, n = 3`
- 输出：`["..#","#.."]`，唯一路径为 $`(0,0) \to (0,1) \to (1,1) \to (1,2)`$。本解法会返回另一个合法答案 `["...","##."]`。

**关键要求**

1. $`1 \le m, n \le 25`$，所以 $`1 \times 1`$、单行、单列都是合法输入。
2. 路径只能向右或向下，起点和终点必须是空地。
3. “恰好一条”同时包含两件事：至少一条（存在性），且不超过一条（唯一性）。

## 4. 算法表达（Algorithm Specification）

**算法名称：** L 形通道构造（L-Shaped Corridor Construction）

### 4.1 输入（Input）

两个整数 $`m, n`$，满足 $`1 \le m, n \le 25`$。

### 4.2 输出（Output）

长度为 $`m`$ 的字符串数组 $`G`$，每个字符串长度为 $`n`$，字符取自 $`\{\texttt{.}, \texttt{\#}\}`$。

记空地集合为 $`F = \{(i, j) : G[i][j] = \texttt{.}\}`$。一条**单调路径**是格子序列 $`(0,0) = c_0, c_1, \ldots, c_k = (m-1, n-1)`$，相邻两格满足 $`c_{t+1} = c_t + (0, 1)`$（向右）或 $`c_{t+1} = c_t + (1, 0)`$（向下）。输出必须满足：

- 全部格子都在 $`F`$ 中的单调路径恰好有一条。

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
CREATE-GRID(m, n)
    res ← 长度为 m 的字符串数组
    res[0] ← n 个 '.'

    for i ← 1 to m - 1
        res[i] ← (n - 1) 个 '#' 后接一个 '.'

    return res
```

构造出的空地集合为首行与末列的并：

```math
F = \{(0, j) : 0 \le j < n\} \cup \{(i, n-1) : 0 \le i < m\}
```

**状态定义**

- `res[0]`：首行，全部为空地。
- `res[i]`（$`i \ge 1`$）：只有最后一列 $`n-1`$ 为空地。

### 4.4 正确性（Correctness）

**证明方法：存在性直接构造 + 唯一性看第一次向下移动**

#### 一、正确性依赖的关键条件

算法正确性依赖于：

1. **步数固定**（由移动规则推出）：任意单调路径恰好包含 $`n-1`$ 次向右和 $`m-1`$ 次向下，因为列号从 0 增到 $`n-1`$、行号从 0 增到 $`m-1`$，每步只让其中一个加 1。
2. **第 $`i \ge 1`$ 行只有末列是空地**（由构造给出）：进入任何 $`i \ge 1`$ 的行，都只能落在第 $`n-1`$ 列。
3. **起点与终点是空地**（由构造给出）：$`(0, 0)`$ 在首行；$`(m-1, n-1)`$ 在末列。$`m = 1`$ 或 $`n = 1`$ 时两者同样成立。

性质 1 和性质 2 合起来说明：路径一旦向下，就已经在最后一列，此后只能一直向下。

#### 二、正确性证明

记 $`P^*`$ 为沿首行走到 $`(0, n-1)`$、再沿末列走到 $`(m-1, n-1)`$ 的路径：

```math
P^* : (0,0) \to (0,1) \to \cdots \to (0,n-1) \to (1,n-1) \to \cdots \to (m-1,n-1)
```

**存在性**

$`P^*`$ 前 $`n`$ 个格子在首行，其余格子在末列，都属于 $`F`$；每步都是向右或向下。所以 $`P^*`$ 是一条合法路径。$`m = 1`$ 时 $`P^*`$ 只有向右的部分，$`n = 1`$ 时只有向下的部分，结论不变。

**唯一性**

任取一条合法路径 $`P`$。

- **若 $`m = 1`$**：路径没有向下移动，只能连续向右 $`n-1`$ 次，即 $`P = P^*`$。
- **若 $`m \ge 2`$**：路径至少向下一次。设第一次向下是从 $`(0, j)`$ 走到 $`(1, j)`$。在此之前路径只在首行向右走，所以已经走了 $`j`$ 次向右。$`(1, j)`$ 必须是空地，由性质 2 得 $`j = n-1`$，也就是 $`n-1`$ 次向右已经全部用完。由性质 1，剩下的 $`m-1`$ 步全部是向下，路径沿末列走到终点。于是 $`P = P^*`$。

两种情况下，任意合法路径都等于 $`P^*`$。

#### 三、结论

对所有 $`1 \le m, n \le 25`$，构造出的网格中合法路径存在，且只有 $`P^*`$ 一条，所以输出满足题目要求。证明没有用到 $`m, n`$ 的上界，对任意正整数 $`m, n`$ 都成立。

### 4.5 复杂度分析（Complexity Analysis）

设网格为 $`m`$ 行 $`n`$ 列。

**时间复杂度：O(mn)**

首行生成 $`n`$ 个字符；其余 $`m-1`$ 行各生成 $`n-1`$ 个 `#`，再拼接成长度为 $`n`$ 的新字符串，每行 $`O(n)`$。合计 $`O(mn)`$。输出本身有 $`mn`$ 个字符，所以任何算法都至少需要 $`\Omega(mn)`$ 时间写出答案。

**空间复杂度：输出 O(mn)，不计输出的额外空间 O(n)**

输出数组占 $`O(mn)`$。Go 实现中，`strings.Repeat("#", n-1) + "."` 会先生成一个长度为 $`n-1`$ 的临时字符串，再拼接成新串，临时串在本次循环后即可回收，所以同一时刻的额外空间为 $`O(n)`$。

### 4.6 测试设计（Test Design）

题目接受任意合法网格，所以测试不和某个固定答案比较，而是写一个**验证器** `checkGrid`，检查三件事：

1. 行数为 $`m`$，每行长度为 $`n`$。
2. 每个字符都是 `.` 或 `#`。
3. `countPaths` 统计的合法路径数等于 1。

`countPaths` 用动态规划计数：$`dp[i][j]`$ 表示从起点到 $`(i, j)`$ 的合法路径数，空地上 $`dp[i][j] = dp[i-1][j] + dp[i][j-1]`$（越界项记为 0），障碍上为 0。

| 测试 | 内容 | 目的 |
|---|---|---|
| `TestCreateGrid` | 三个题目示例的尺寸，加上 $`1 \times 1`$、$`4 \times 1`$、$`25 \times 25`$ | 覆盖单格、单行、单列和最大尺寸 |
| `TestCreateGridAllSizes` | $`1 \le m, n \le 25`$ 的全部 625 种尺寸 | 约束范围很小，可以全部枚举 |
| `TestCountPaths` | 全空 $`2 \times 2`$（2 条）、全空 $`3 \times 3`$（6 条）、终点被堵（0 条）、题目示例 3 的答案（1 条） | 先确认验证器自己算得对，否则验证器出错时测试会误报通过 |

全空 $`3 \times 3`$ 的期望值 6 来自组合计数：4 步中选 2 步向下，$`\binom{4}{2} = 6`$。

## 5. 思维难点（Learning Notes）

### 难点一：“恰好一条”要拆成两半证明

只验证“能走到终点”是不够的。比如全空网格一定能走到终点，但 $`m, n \ge 2`$ 时路径不止一条。

**理解过程**

把“恰好一条”拆成“至少一条”和“至多一条”。前者给出一条具体路径即可；后者要说明任何合法路径都只能是这一条。唯一性论证抓住第一次向下的位置：首行以下只有末列可走，所以第一次向下只能发生在最后一列。

**可迁移思维：** 证明“恰好 $`k`$ 个”时，分别证明下界和上界；唯一性常用“任取一个解，说明它必须等于构造的解”来证。

### 难点二：答案不唯一时测试怎么写

题目示例给的是 `["..#","#.."]`，本解法返回 `["...","##."]`。两者都对，直接比较字符串会让正确的代码测试失败。

**理解过程**

测试应该检查输出是否满足题目条件，而不是输出是否等于某个答案。这里的条件“路径数为 1”可以用网格路径计数的动态规划直接算出来。验证器本身也要用已知结果的小网格单独测一遍。

**可迁移思维：** 构造题、输出任意解的题，测试写成验证器；验证器的规则要比被测算法简单、容易确认正确。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Constructive Algorithms（构造）**：在本题中，不去搜索满足条件的网格，而是直接给出一个结构简单、容易证明的网格。适用于“输出任意满足条件的对象”的题目。限制是构造本身需要观察，正确性必须单独证明，不能只靠样例。
2. **Uniqueness by First Deviation（看第一次偏离证唯一性）**：在本题中，比较任意路径与 $`P^*`$ 的第一处不同，发现那一步必然踩到障碍。适用于证明路径、序列或方案唯一。前提是能说明“偏离的那一步”一定违反约束。
3. **Validator-Based Testing（验证器测试）**：在本题中，`checkGrid` 检查尺寸、字符集和路径数，不依赖具体答案。适用于答案不唯一的题。前提是验证条件可以高效计算，并且验证器本身经过测试。
4. **Grid Path Counting DP（网格路径计数动态规划）**：在本题中只用于测试，$`dp[i][j] = dp[i-1][j] + dp[i][j-1]`$。适用于只能向右、向下的网格路径计数。结果可能很大时要注意溢出，本题网格最多 $`25 \times 25`$，测试中的网格路径数都很小。
