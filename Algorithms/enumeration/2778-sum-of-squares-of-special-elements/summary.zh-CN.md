## 2. 题意理解（Problem Understanding）

给定一个长度为 n 的整数数组 `nums`，**下标从 1 开始**。

如果下标 `i` 满足 `n % i == 0`，则称 `nums[i]` 是**特殊元素**。

返回所有特殊元素的平方和。

关键约束：

1. 下标从 1 开始，而 Go 的切片下标从 0 开始。
2. 判断条件是 **`i` 能整除数组长度 n**，而不是 `i` 能整除元素值。
3. 数据范围很小（$`1 \leq n \leq 50`$），暴力即可通过。

### 核心问题

本题的任务是：**找出 n 的所有因数，并按因数取下标。**

例如 `n = 4`：

- 因数为 `1, 2, 4`。
- 对应元素为 `nums[1], nums[2], nums[4]`（1-indexed）。
- 即 Go 中的 `nums[0], nums[1], nums[3]`。

## 3. 初始思路（Initial Approach）

### 3.1 最直接的想法：从 1 枚举到 n

```go
for i := 1; i <= n; i++ {
    if n%i == 0 {
        res += nums[i-1] * nums[i-1]
    }
}
```

正确，时间复杂度 O(n)。对 $`n \leq 50`$ 完全足够。

### 3.2 进一步优化：因数成对出现

如果 `i` 是 n 的因数，那么 `n/i` 也是 n 的因数。

两者一个不超过 √n，另一个不小于 √n。

因此，只需要枚举 `i` 从 1 到 √n：

- 每找到一个因数 `i`，同时得到另一个因数 `n/i`。
- 两个下标都需要累加。

### 3.3 特殊情况：完全平方数

当 `i * i == n` 时，`i` 与 `n/i` 是**同一个因数**。

此时只能累加一次，否则会重复计算。

这就是代码中 `if i*i < n` 的作用。

### 思维转变总结

从：

> 逐个检查每个下标是否整除 n。

转变为：

> 因数成对出现，只需检查较小的一半，另一半由配对关系直接得到。

**核心认知：当目标对象具有对称或配对结构时，可以只枚举一半，另一半通过映射得到。**

## 4. 算法表达（Algorithm Specification）

**算法名称：** 成对因数枚举（Paired Divisor Enumeration）

### 4.1 输入（Input）

输入长度为 n 的整数数组：

$$
nums = \langle a_1, a_2, \ldots, a_n \rangle
$$

**前置条件：**

- **长度约束**：$`1 \leq n \leq 50`$。
- **元素约束**：$`1 \leq a_i \leq 50`$。
- **下标约定**：题面使用 1-indexed，Go 实现中访问 `nums[i-1]`。

### 4.2 输出（Output）

输出一个整数 `res`：

$$
res = \sum_{\substack{1 \leq i \leq n \\ i \mid n}} a_i^2
$$

### 4.3 伪代码（Pseudocode）

```text
SUM-OF-SQUARES(nums)
    n ← length(nums)
    res ← 0

    for i ← 1 while i * i ≤ n
        if n mod i == 0
            res ← res + nums[i]²

            if i * i < n
                res ← res + nums[n / i]²

    return res
```

**状态定义**

- `n`：数组长度，同时是被分解的数。
- `i`：当前枚举的较小因数，满足 $`i \leq \sqrt{n}`$。
- `n/i`：与 `i` 配对的较大因数。
- `res`：已累加的特殊元素平方和。

### 4.4 正确性（Correctness）

**证明方法：因数配对的双射 + 循环不变式**

#### 一、关键性质

**性质 A：因数成对出现**

设 `d` 是 n 的因数，则 `n/d` 也是 n 的因数，且

$$
d \cdot \frac{n}{d} = n
$$

所以 `d` 与 `n/d` 中必有一个不超过 √n。

**性质 B：映射 $`d \mapsto n/d`$ 是双射**

该映射把"不超过 √n 的因数"一一对应到"不小于 √n 的因数"。

- 当 $`d < \sqrt{n}`$ 时，$`n/d > \sqrt{n}`$，两者不同。
- 当 $`d = \sqrt{n}`$ 时，$`n/d = d`$，是同一个因数。

#### 二、循环不变式

设已经处理完 $`i = 1, 2, \ldots, k`$。

**不变式：** `res` 等于所有满足"$`d \mid n`$ 且（$`d \leq k`$ 或 $`n/d \leq k`$）"的因数 `d` 所对应元素的平方和，每个因数恰好计入一次。

#### 三、证明（Proof）

**1. 初始化**

$`k = 0`$ 时，没有处理任何 `i`，`res = 0`，不变式成立。

**2. 保持**

处理 $`i = k+1`$：

- 若 `n % i != 0`：`i` 不是因数，`res` 不变，不变式保持。
- 若 `n % i == 0` 且 `i*i < n`：`i` 与 `n/i` 是两个不同的因数，分别累加一次。
- 若 `n % i == 0` 且 `i*i == n`：`i == n/i`，只累加一次。

三种情况下，每个因数都恰好计入一次。

**3. 终止**

循环在 `i*i > n` 时结束，此时 $`i > \sqrt{n}`$。

任意因数 `d` 满足 $`d \leq \sqrt{n}`$ 或 $`n/d \leq \sqrt{n}`$，因此都已被覆盖。

由不变式，`res` 恰好是全部因数对应元素的平方和。

### 4.5 复杂度分析（Complexity Analysis）

**时间复杂度：O(√n)**

循环变量 `i` 满足 $`i^2 \leq n`$，最多执行 $`\lfloor\sqrt{n}\rfloor`$ 次，每次为常数操作。

**额外空间复杂度：O(1)**

只使用 `n`、`res`、`i` 三个变量。

> 说明：本题 $`n \leq 50`$，O(n) 与 O(√n) 在性能上没有区别。使用 √n 写法的价值在于练习模板。

## 5. 思维难点（Learning Notes）

### 难点一：为什么需要 `i*i < n`？

以 `n = 4` 为例：

```text
i = 1：因数对 (1, 4)，累加 nums[0] 和 nums[3]
i = 2：因数对 (2, 2)，只累加 nums[1] 一次
```

如果没有 `i*i < n`，`i = 2` 时会累加 `nums[1]` 两次。

**可迁移思维：配对枚举要先问"两端会不会重合"，重合点必须单独处理。**

### 难点二：条件是下标整除 n，不是元素值整除

题目判断的是**下标 `i`** 能否整除**数组长度 n**，与 `nums[i]` 的值无关。

**可迁移思维：读题时先区分"位置"和"数值"，两者在数组题里极易混淆。**

## 6. 可迁移知识（Key Takeaways）

### 6.1 枚举到 √n 的成对因数模板

```go
for i := 1; i*i <= n; i++ {
    if n%i == 0 {
        // 处理因数 i
        if i*i < n {
            // 处理配对因数 n/i
        }
    }
}
```

这个模板可以迁移到：

- 求因数个数、因数和。
- 判断质数、判断完美数。
- 求第 k 个因数。
- 求两个数的公因数数量。

### 6.2 配对枚举的一般思想

当对象具有"成对"结构时：

1. 只枚举其中较小的一半。
2. 用映射得到另一半。
3. 单独处理两半重合的位置。

### 6.3 暴力与优化的取舍

数据范围很小时，直接 O(n) 更不容易出错。

但练习阶段可以刻意使用 O(√n) 写法，把它整理成模板，以便在数据范围更大的题目中直接使用。
